# AccidentCases Agent Memory

เอกสารนี้ใช้เป็นบริบทถาวรสำหรับงานรายงานอุบัติเหตุ เพื่อให้ทำงานต่อได้แม้เปลี่ยนแชท

## เป้าหมายโมดูล
- ใช้ HTML เป็นเอกสารหลัก (แก้ไขได้, พิมพ์เป็น PDF ได้)
- 1 เคส = 1 โฟลเดอร์ (มี `index.html` + `assets/images|maps|docs`)
- รองรับแนบหลักฐาน, เปิดไฟล์อ้างอิง, และพิมพ์รายงานพร้อมรูป

## มาตรฐานที่ตกลงแล้ว (Current Standard)
- ชื่อเอกสารใช้โค้ด `AIR`
- `Doc No.` อยู่ใต้กรอบหัวกระดาษ (ไม่อยู่ในกรอบ)
- หัวข้อ Timeline มีคอลัมน์ `วันที่ | เวลา | เหตุการณ์`
- คำตอบข้อ 1 และ 2 มีระยะย่อหน้าเท่าข้ออื่น
- ใช้คำว่า `ภาพหลักฐานแนบ`
- ลายเซ็น 2 ช่อง: `ผู้จัดทำรายงาน` และ `ผู้ขับขี่รับทราบ`
- กรอง `yk_logo_mark.svg` ไม่ให้เข้า evidence
- ปุ่มพิมพ์ต้องรอรูปโหลดก่อน เพื่อให้รูปติดตอน Print/PDF

## วิธีเปิดใช้งานที่แนะนำ
- ใช้ `AccidentCases/run_local_server.bat` เป็นหลัก
- รองรับเปิดเคสตรงด้วย argument เช่น:
  - `run_local_server.bat 2026-04-25_71-8008`

## กติกาอัปเดตบริบท
- เมื่อมีข้อสรุปใหม่ ให้เพิ่มบันทึกใน `AccidentCases/DECISION_LOG.md` ทันที
- หากเปลี่ยน template ให้ระบุผลกระทบกับเคสใหม่ใน log ด้วย
- หากมีมาตรฐานใหม่ ให้แก้หน้านี้ในหัวข้อ `Current Standard`
