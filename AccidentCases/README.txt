AccidentCases - โครงเก็บไฟล์รายงานอุบัติเหตุ

แนวทางใช้งาน (1 เคส = 1 โฟลเดอร์):
1) คัดลอกโฟลเดอร์ _TEMPLATE_CASE แล้วตั้งชื่อใหม่ เช่น
   2026-04-25_71-8008
2) นำไฟล์หลักฐานไปวางใน:
   - assets/images  (รูปถ่ายเหตุการณ์/ความเสียหาย)
   - assets/maps    (แผนที่/เส้นทาง GPS)
   - assets/docs    (เอกสารอื่น เช่น xlsx/pdf/docx)
3) เปิด local server (แนะนำ)
   - ดับเบิลคลิก: run_local_server.bat
   - หรือเปิดเคสตรง ๆ: run_local_server.bat 2026-04-25_71-8008
   ระบบจะเปิด browser ให้อัตโนมัติที่ http://localhost:8765
4) เปิดไฟล์ index.html ของเคสนั้น
5) แก้ไขข้อมูลในช่องที่พิมพ์ได้ (ระบบ autosave ใน browser)
6) เพิ่มรายการหลักฐานได้ 2 แบบ:
   - ลากไฟล์เข้า drop zone (เก็บใน browser local data)
   - เพิ่มลิงก์ไฟล์ในโฟลเดอร์ assets (กดเปิดได้จริงจากไฟล์ในเคส)
7) ใช้ปุ่ม:
   - Export HTML Snapshot: บันทึกไฟล์รายงานที่กรอกแล้ว
   - Export Evidence Log: บันทึกรายการหลักฐานเป็น txt

หมายเหตุ:
- ไฟล์ที่ลากอัปโหลดจะอยู่ใน local data ของ browser เครื่องนั้น
- ถ้าต้องการเก็บถาวรแบบตรวจสอบย้อนหลังง่าย ให้เก็บไฟล์จริงไว้ใน assets
- เวลาย้ายเคสไปเครื่องอื่น ให้คัดลอกทั้งโฟลเดอร์เคส
- การรันผ่าน http://localhost แนะนำมากสำหรับฟีเจอร์เชื่อมโฟลเดอร์เคสและการเปิดไฟล์หลักฐานแบบเสถียร

ไฟล์อ้างอิงถาวรสำหรับคุยต่อข้ามแชท:
- AGENT_MEMORY.md   (มาตรฐานงานล่าสุดที่ตกลงแล้ว)
- DECISION_LOG.md   (บันทึกสิ่งที่ตัดสินใจในแต่ละรอบ)
- ../AGENT_START_HERE.md (จุดเริ่มอ่านเดียวของทั้ง Project YK)
