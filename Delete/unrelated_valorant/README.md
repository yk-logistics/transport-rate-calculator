# Valorant Spike Timer Overlay

- **ปุ่ม 5** = ได้ยินเสียงปลูก Spike แล้วกด → เริ่มนับถอยหลัง 45 วิ (กู้เต็มใช้ 7.5 วิ)
  - **เตือนเตรียมตัว:** เหลือ 12 วิ → เสียงสั้น (ให้รีบเดินไปกู้)
  - **ถึงเวลา:** เหลือ 9 วิ → เสียงชัด (ต้องกู้แล้ว เผื่อที่กดเริ่มช้า ~1 วิ)
- **ปุ่ม 6** = กู้ได้ครึ่งแล้วกด → โหมดกู้ครึ่ง (เหลือ 3.75 วิจะกู้เสร็จ)
  - **เตือนเตรียมตัว:** เหลือ 8 วิ
  - **ถึงเวลา:** เหลือ 5 วิ

## ติดตั้ง

```bash
cd valorant_spike_overlay
pip install -r requirements.txt
```

## วิธีเปิดโปรแกรม

**แบบง่าย (แนะนำ):** ดับเบิลคลิกไฟล์ **`เปิด Spike Timer.bat`** ในโฟลเดอร์นี้ → จะเปิดหน้าต่าง CMD แล้วโปรแกรมรันทันที  

**ปิด overlay:** กด **F10** (ปิดโปรแกรมทันที) หรือปิดหน้าต่าง CMD / กด Ctrl+C ใน CMD

**แบบใช้ CMD เอง:** เปิด Command Prompt แล้วพิมพ์:
```bash
cd "C:\Users\Home\Desktop\Project YK\valorant_spike_overlay"
python spike_overlay.py
```
(หรือ `cd` ไปที่โฟลเดอร์ valorant_spike_overlay ก่อน แล้วค่อย `python spike_overlay.py`)

- Overlay ขนาดเล็กมุมขวาบน (ไม่บังโฟกัส)
- กด **5** เมื่อได้ยินปลูก Spike → นับ 45 → บรรทัดล่าง "กู้เต็ม 7.5 วิ" → เหลือ 12 วิ เตือนเตรียมตัว, เหลือ 9 วิ เตือนถึงเวลา
- กด **6** หลังกู้ครึ่งแล้ว → บรรทัดล่าง "กู้ครึ่ง 3.75 วิ" → เหลือ 8 วิ เตือนเตรียมตัว, เหลือ 5 วิ เตือนถึงเวลา
- หน้าต่างโปร่งใส คลิกทะลุไปเกม

**สองระดับ:** เตือน "เตรียมตัว" (เหลือ 12 วิ / 8 วิ) ให้มีเวลาเดินไปกู้ แล้วเตือน "ถึงเวลา" (9 วิ / 5 วิ) เป็น deadline จริง (เผื่อดีเลย์ตอนกดปุ่มเริ่มเล็กน้อย)

## ทดสอบว่า Overlay ทับ Valorant ได้ไหม

1. รัน `python spike_overlay.py`
2. เปิด Valorant แล้วเข้าเกม (หรือใช้โหมดเต็มจอ)
3. ดูว่าเลขนับถอยหลังโผล่ทับจอเกมหรือไม่

**ถ้าไม่โผล่:** Valorant อาจใช้โหมด Fullscreen แบบ Exclusive  
→ ไปที่ **Settings → Video → Display Mode** เปลี่ยนเป็น **Fullscreen (Windowed)** หรือ **Windowed** แล้วลองใหม่

## ปิดโปรแกรม

ปิดหน้าต่าง overlay (ถ้าคลิกได้) หรือกด Ctrl+C ใน terminal ที่รันคำสั่ง
