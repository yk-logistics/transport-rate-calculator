# เครื่องคิดค่าขนส่งคนขับเหมา AYU–Yusen (60%) — Design

วันที่: 2026-06-29
สถานะ: รออนุมัติ spec จากโอ

## ปัญหา

คนขับเหมา AYU ที่วิ่งงานลูกค้า Yusen (Charter) ต้องได้ค่าขนส่ง **60% ของรายได้สุทธิจริงต่อเที่ยว** แต่ตอนนี้ payrun AYU#18 มีคนขับกลุ่มนี้ (`ayu_mao`) ค้าง "เหมารอราคา" เพราะยังไม่มีสูตรคิดราคาที่ชัด (ref: project-ayu-jun-payroll, project-ayu-daily-import)

ไฟล์ต้นทาง = `CHARTER Y.K. <เดือน>.xlsx` (ใบวางบิลที่ YK เก็บจากลูกค้า) — มีราคากลางต่อเที่ยวที่คนคีย์ลงไว้ + รายละเอียดบวก/ลบครบ

## เป้าหมาย (scope งานนี้)

เครื่องคำนวณ (CLI/สคริปต์ **read-only**) ที่:
- รับไฟล์ CHARTER ของเดือนหนึ่ง + ราคาน้ำมันเฉลี่ยของรอบ
- ออกรายงาน **เงินที่ควรจ่ายคนขับ** ต่อเที่ยว + สรุปต่อคน + ยอดรวม
- ตรวจย้อนกลับได้ในตัว

ทำให้โอเห็นตัวเลขและเทียบกับของจริงก่อน แล้วค่อยตัดสินว่าจะเอาเข้า payrun ทีหลัง (งานคนละก้อน)

## ไม่ทำ (YAGNI / กันความเสี่ยง)

- **ไม่แตะ** payrun / DB / FuelTxn / `services/payroll.py` — มี session อื่นแตะ payroll อยู่
- **ไม่ scrape** เว็บราคาน้ำมันบางจาก — เปราะ พังเวลาเว็บเปลี่ยน; โอกรอกราคาเฉลี่ยของรอบเอง (มีเครื่องมือแคปหน้าจอบางจากอยู่แล้ว แม่นอยู่แล้ว)
- **ไม่หัก** ค่าน้ำมันที่คนขับเติมจริง — โอยืนยันคิดต่างหาก งานนี้คิดเฉพาะ "ค่าขนส่ง 60%"
- **ไม่ deploy / ไม่เขียนลง DB** จนกว่าโอตรวจตัวเลขผ่าน

## คำศัพท์ (ตกลงใช้ร่วมกันในอนาคต)

- **ราคาน้ำมันอ้างอิงของรอบ** (cycle fuel reference price) = ค่าเฉลี่ยราคาไฮดีเซล S ของบางจาก ตามช่วงวันที่ของรอบลูกค้า (เช่น รอบ 26/5–25/6 = 39.88 บ./ล.) — โอคำนวณจากเครื่องมือ `transport-rate-calculator` แล้วกรอกเข้าเครื่องนี้
- **ค่าผันน้ำมัน / fuel surcharge** = % ที่บวกเข้าค่าขนส่งตามตาราง range ของราคาน้ำมัน

## Input

1. ไฟล์ CHARTER `.xlsx` (ชีทเดียว เช่น "May 26")
2. ราคาน้ำมันอ้างอิงของรอบ (ตัวเลข เช่น `39.88`) — พารามิเตอร์ที่โอกรอก

## โครงสร้างไฟล์ CHARTER (อ้างอิงจริงจากไฟล์ พ.ค.)

### ส่วนรายเที่ยว (หัวตารางแถว 3, ข้อมูลแถว 4 ลงไป)
จับคอลัมน์ **ด้วยชื่อหัวตาราง** ไม่ใช่ตัวอักษรคอลัมน์ (กันไฟล์เลื่อน):
- `Driver Name` (H) — ชื่อคนขับ
- `Cost` (AG) — ค่าขนส่งฐานต่อเที่ยว (ราคากลางที่คนคีย์)
- `WaitingCharge` / `Drop Cost` / `LaborCost` / `BackhaulCost` / `othercost` — รายการบวก
- `TotalCost` (AV) — รวมต่อเที่ยว = Cost + รายการบวก
- นับเป็นเที่ยวเมื่อคอลัมน์ `Item` (A) เป็นตัวเลข

ไฟล์ พ.ค.: 18 แถว, คนขับ 4 คน (เรวัตร, รุ่งเรือง, วัชร์นล นันทะเดช, สมปอง), ΣCost=50,062, ΣTotalCost=50,662

### ส่วนสรุปท้ายตาราง (อ่าน auto ด้วยคำในป้าย ภาษาไทย — กันแถวขยับ)
| ป้าย (คอลัมน์ AU) | ค่า (AV) | เครื่องใช้ทำอะไร |
|---|---|---|
| `รวมค่าขนส่ง (ค่ารถ...)` | 50,062 | cross-check ΣCost |
| `บวก ค่าขนส่งน้ำมันเพิ่มขึ้น N%` | 6,007.44 | (ไฟล์ใช้ 12% — เครื่อง **คิดใหม่จากราคาน้ำมัน** ไม่ลอกค่านี้) |
| `ค่าขนส่ง (ค่าดรอบ+ค่ารอ+...)` | 400 | extras รวมรอบ |
| `หัก ส่วนลดค่าขนส่ง 1%` | 564.69 | อัตราส่วนลดค่าขนส่ง (อ่าน % จากป้าย) |
| `ค่าพนักงานยกสินค้า` | 200 | labor รวมรอบ |
| `หัก ส่วนลดค่าพนักงานยกสินค้า 1%` | 2 | ส่วนลด labor |
| `หัก ค่าบริการ TMS` | 800 | ค่าบริการ TMS (อ่านยอดตรง) |
| `รวมยอดสุทธิ` | 55,302.75 | NET (cross-check) |

### ตาราง range surcharge (คอลัมน์ AX=ช่วงราคา, AY=%)
| ช่วงราคาน้ำมัน | surcharge |
|---|---|
| 28.00–29.99 | 0% |
| 30.00–31.99 | 2% |
| 32.00–33.99 | 4% |
| 34.00–35.99 | 6% |
| 36.00–37.99 | 8% |
| 38.00–39.99 | 10% |
| 40.00–41.99 | 12% |

**นอกตาราง:** extrapolate ต่อ 2% ทุก 2 บาท (>42 เพิ่มขึ้นเรื่อย ๆ, <28 = 0%)
สูตร: `surcharge% = max(0, floor((price − 28) / 2)) × 2%` — เช็คกับตาราง: 39.88 → floor((39.88−28)/2)=floor(5.94)=5 → 10% ✓; 40.99 → floor(6.495)=6 → 12% ✓

## สูตรคิด

```
สำหรับเดือนหนึ่ง + ราคาน้ำมันอ้างอิง p:

1. surcharge = range_lookup(p)                       # เช่น 39.88 → 0.10
2. base       = Σ Cost(AG) ของทุกเที่ยว              # 50,062
3. extras     = ค่า "ค่าดรอบ+ค่ารอ+ค้างคืน+ยกเลิก"   # 400  (อ่านจากป้าย)
4. disc_rate  = อัตราส่วนลดค่าขนส่ง                   # 0.01 (อ่าน % จากป้าย)
5. labor      = ค่าพนักงานยกสินค้า                    # 200  (อ่านจากป้าย)
6. labor_disc = ส่วนลด labor                          # labor × disc_rate
7. tms        = ค่าบริการ TMS                         # 800  (อ่านยอดตรง)

   transport_sub = base × (1 + surcharge) + extras
   net = transport_sub × (1 − disc_rate) + (labor − labor_disc) − tms

8. effective_rate = net / Σ TotalCost(AV)

   ต่อเที่ยว: driver_pay = TotalCost(เที่ยว) × effective_rate × 0.60
```

`effective_rate` ม้วน surcharge + ส่วนลด 1% + TMS + extras เป็นอัตราเดียว แล้วเฉลี่ยลงแต่ละเที่ยวตามสัดส่วนรายได้ — ตรงกับที่โอบอก "เฉลี่ยเที่ยวทั้งเดือนก็ได้"

อัตราส่วนแบ่ง 60% = ค่าคงที่ `DRIVER_SHARE = 0.60` (ตรงกับ `LCB_MAO_RATIO` เดิมในระบบ)

## Output (รายงาน)

1. **หัวรอบ:** ราคาน้ำมันอ้างอิง, surcharge%, base, extras, NET, effective_rate
2. **ต่อเที่ยว:** item / คนขับ / TotalCost / driver_pay
3. **สรุปต่อคน:** คนขับ → จำนวนเที่ยว, Σ TotalCost, Σ driver_pay
4. **ยอดรวม:** Σ driver_pay ทั้งรอบ

รูปแบบ: ข้อความสรุปไทยให้โออ่าน + ตาราง (CSV/console)

## ตรวจย้อนกลับ (preflight ในตัว)

1. **Σ driver_pay = NET × 0.60 เป๊ะ** (ถ้าไม่ตรง = เฉลี่ยพลาด) — เดือน พ.ค. ตัวอย่าง: 55,302.75 × 0.60 = 33,181.65
2. **cross-check base:** ΣCost(AG) ที่เครื่องอ่าน = ป้าย "รวมค่าขนส่ง" (50,062)
3. **cross-check NET (เฉพาะเมื่อ surcharge ตรงไฟล์):** ถ้าราคาน้ำมันที่กรอกตกใน band เดียวกับที่ไฟล์ใช้ → NET ที่เครื่องคิด = ป้าย "รวมยอดสุทธิ" ของไฟล์ (กับไฟล์ พ.ค. ที่ใช้ 12%, ใส่ราคา 40.99 → ต้องได้ 55,302.75)
4. **ครบเที่ยว:** จำนวนเที่ยวที่อ่าน = จำนวนแถว Item ในไฟล์

## Decisions ที่โอยืนยันแล้ว

- 60% = เงินคนขับ (driver pay) ไม่ใช่ revenue ลง CFO
- ฐาน 60% = รวม extra รายเที่ยว + ผันน้ำมัน + หัก 1%/TMS เฉลี่ย (= NET จริงต่อเที่ยว)
- surcharge **คิดสดจากราคาน้ำมันของรอบ** (เดือนนี้ 39.88 → 10%) ไม่ลอก 12% ดิบจากไฟล์
- นอกตาราง: extrapolate ±2%/2฿
- ราคาน้ำมันอ้างอิง: โอกรอกเอง (ไม่ scrape)
- TMS/labor/discount: เครื่องอ่าน auto จากไฟล์แต่ละเดือน
- ไม่หักค่าน้ำมันคนขับเติม (คิดต่างหาก)
