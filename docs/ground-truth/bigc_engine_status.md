# BIGC engine คำนวณเอง — สถานะ + สิ่งที่ต้องคุยกับโอ

อัปเดต 2026-06-28 (ต่อจาก night-run). โอขอ "ให้ engine คำนวณเอง ลองให้สุด ถ้าติดค่อยคุย".

## ผลประเมิน: engine BIGC คำนวณเองได้บางส่วน — ติดที่ "ค่าเที่ยว"

engine `bigc_monthly` (services/payroll.py:944) ต้องการ 3 input:
| input | สถานะ | หมายเหตุ |
|-------|-------|---------|
| **base salary ต่อคน** | ✅ ทำแล้ว | set `employee.base_salary` จาก รวม YK: ส่วนใหญ่ 9,000, บุญชอบ 1,800, กฤษฎา 2,100, พรศักดิ์ 0 |
| **fuel rebate** | ⚠️ เกือบได้ | import_bigc_fuel_rate.py สร้าง PayRunAdjust ให้ตรง admin. verify 5/7 ตรง (diff <0.1), 2 คน (สมประสงค์/เกศศักดิ์) diff ~260 เพราะ residual ติดลบคำนวณคนละทาง |
| **trip fee (ค่าเที่ยว)** | ❌ ติด | ดึงจาก DailyJob.trip_fee_driver — **แต่ BIGC ไม่มี daily ใน DB เลย (0 แถว)** |

## 🔴 BLOCKER ต้องถามโอ: ค่าเที่ยว BIGC ดึงจากไหน?

ค่าเที่ยวกระจายหลายชีท ไม่มีแหล่งเดียวครบ:
- ชีทเรทน้ำมัน (col 6 ค่าเที่ยวพขร): มีบางคน (เกรียงไกร 18,000, สมัย 14,000) **แต่หลายคน fee=0** (ชรินทร์/เสกสรร/สมประสงค์/มานพ = 0)
- แต่ รวม YK บอกเสกสรร 15,200, สมประสงค์ 16,250, มานพ 10,300 → ค่าเที่ยวพวกนี้อยู่ที่อื่น
- ชีทรายคนใน Book1 (เกรียงไกร, สมประสงค์, ...) น่าจะมี — แต่ format ต่อคนต่างกัน
- ชื่อในชีทเรทน้ำมันไม่ตรง roster (อาท, ชรินทร์, โกสินทร์ = คนขับ CJ ปนมา)

**คำถามโอ:** ค่าเที่ยวแต่ละคนที่ใส่ใน รวม YK เอามาจากชีทไหนกันแน่? (ชีทรายคน Book1? Daily report? รวมหลายแหล่ง?) ถ้ารู้แหล่งเดียวที่ครบ → ผม parse เข้า DailyJob แล้ว engine คำนวณเองได้

## ⚠️ บั๊กที่เจอ: import_bigc_fuel_rate.py ทับยอดลอก
tool เรียก `compute_pay_run(recompute=True)` ตอนจบ → ทับ PayRunItem ที่ลอกยอด (พ.ค. 110,614 → 92,771 ผิด เพราะ trip ยังไม่ครบ). COPY-LOCK guard กันไม่ได้เพราะ tool ไม่ผ่าน route.
→ กู้คืนจาก backup แล้ว. **ก่อนใช้ tool นี้กับ BIGC ลอกยอด: ต้องแก้ tool ไม่ให้ auto-recompute payrun ที่ [COPY-LOCK] หรือ skip recompute.**

## สถานะปัจจุบัน (ปลอดภัย)
- base_salary set ไว้แล้ว 11 คน (ไม่กระทบ payrun ลอกยอด เพราะลอกยอดไม่ใช้ engine).
- payrun BIGC/AYU ยังลอกยอดถูกต้อง (พ.ค. 110,614 ฯลฯ).
- ยังไม่ import daily/fuel BIGC เข้า DB (กันทับยอด).

## ถ้าจะเดินต่อ (หลังคุยกับโอ)
1. โอบอกแหล่งค่าเที่ยว → parse เข้า DailyJob (driver_id ต่อเที่ยว, ระวังรถสลับ 71-8001 ธนวัฒน์ออก/มานพเริ่ม).
2. แก้ import_bigc_fuel_rate.py กัน auto-recompute COPY-LOCK payrun.
3. import fuel + daily → recompute → เทียบ vs รวม YK. ตรง = engine BIGC ทำงานเอง → ปลด COPY-LOCK.
4. AYU ซับซ้อนกว่า (2-ระบบ + หลาย sub-model) — ทำหลัง BIGC สำเร็จ.
