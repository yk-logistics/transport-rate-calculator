## ⚠️ Finance/CFO payroll cost ย้อนหลัง — ต่ำกว่าจริง (AYU + LCB ม.ค.-เม.ย.)

เจอตอนทำงานต่อ: finance ดึง payroll cost จาก gross_total. payrun ที่ engine คำนวณ (LCB พ.ค./มิ.ย., **BIGC ทุกเดือน**) gross ถูก. แต่ที่ลอกยอด (**AYU ทุกเดือน + LCB ม.ค.-เม.ย.**) ผมใส่ gross=net (ลอกแค่ net จากแบงค์ ไม่มี gross จริง) → finance มองต้นทุนเงินเดือนย้อนหลังพวกนี้ **ต่ำกว่าจริง ~30-50%** (ขาดส่วนเบิก+น้ำมันที่บริษัทออก).

**ไม่แก้คืนนี้** เพราะไม่มี gross จริง — แก้ = ต้อง import เบิก/น้ำมันย้อนหลัง (งานใหญ่) หรือใส่เลขเดา (เสี่ยง). รายละเอียด + 3 ทางเลือก (ปล่อย/import/ลบ) อยู่ใน `finance_payroll_note.md`. **เดือนที่จะ finalize จริงไม่กระทบ** (LCB มิ.ย./BIGC พ.ค. gross ถูก; AYU พ.ค. ลอกยอดเหมือนกัน).
