# ⚠️ Finance/CFO + payroll cost ย้อนหลัง — limitation ที่ต้องรู้

พบ night-run 2026-06-28. **เรื่องเงิน — โอตัดสินใจ ผมไม่แก้เดาๆ**

## ปัญหา
`services/finance.py` คำนวณ payroll cost = **sum(PayRunItem.gross_total)** ตาม pay_cycle_tag.
gross_total ที่ถูก = ต้นทุนเงินเดือนเต็ม (รายได้ก่อนหักเบิก/น้ำมัน) = เงินที่บริษัทจ่ายจริง.

payrun คืนนี้แบ่ง 2 กลุ่ม:
| กลุ่ม | gross_total | ถูกสำหรับ finance? |
|-------|-------------|-------------------|
| engine คำนวณ (LCB พ.ค./มิ.ย., **BIGC ทุกเดือน**) | gross จริง (>> net) | ✅ ถูก |
| ลอกยอด (**AYU ทุกเดือน, LCB ม.ค.–เม.ย.**) | = net (ลอกแค่ net จากแบงค์) | ❌ undercount |

## ผลกระทบ (ตัวเลขจริง)
- BIGC ลอกยอดแต่มี gross จริงจากชีท รวม YK → ถูก (เช่น ธ.ค. gross 203,918 vs net 116,187).
- **AYU ม.ค.–พ.ค. + LCB ม.ค.–เม.ย.: gross=net** → finance มองว่า payroll cost = ยอดโอนสุทธิ
  ซึ่ง**ต่ำกว่าจริง** (ขาดส่วนเบิกล่วงหน้า + น้ำมันที่บริษัทออกก่อนแล้วหักทีหลัง).
- ประมาณ undercount: ดูจาก BIGC/LCB ที่มี gross จริง ส่วนต่าง gross−net ~30-50% ของ net
  → AYU/LCB ย้อนหลัง payroll cost จริงน่าจะสูงกว่าที่ finance แสดง ~30-50%.

## ทำไมไม่แก้คืนนี้
ลอกยอด AYU/LCB ย้อนหลัง **ไม่มี gross จริง** (แบงค์มีแค่ net โอน). จะแก้ให้ถูกต้อง:
1. import ข้อมูลเบิกล่วงหน้า (petty) + น้ำมัน ย้อนหลังของ AYU/LCB ม.ค.–เม.ย. → คำนวณ gross
2. หรือใส่ gross เดาจาก ratio (เสี่ยง — ตัวเลขมั่ว เข้า finance)
ทั้งคู่ = งานใหญ่ที่กระทบเงิน ต้องโอยืนยัน. การใส่ net เป็น gross ตอนนี้ = conservative
(ไม่ทำให้ตัวเลขพอง แค่ต่ำกว่าจริง) ดีกว่าใส่เลขเดา.

## ทางเลือกให้โอ (เลือกตอนสะดวก)
- **A. ปล่อยไว้** — finance ย้อนหลัง AYU/LCB ม.ค.-เม.ย. = payroll cost ตาม net (ต่ำกว่าจริง ~30-50%).
  เดือนปัจจุบัน (LCB มิ.ย./BIGC พ.ค.) gross ถูกอยู่แล้ว. ประวัติย้อนหลังใช้ดูแนวโน้มได้ แค่ตัวเลข cost ต่ำ.
- **B. import เบิก+น้ำมันย้อนหลัง** — ให้ engine คำนวณ gross จริง (งานใหญ่ ต้องมีไฟล์ครบ).
- **C. ลบ payrun ย้อนหลัง** — ถ้าไม่อยากให้ finance เพี้ยน เก็บแค่เดือนที่ engine คำนวณ.

## หมายเหตุ
ไม่กระทบ payrun ที่จะ finalize จริง (LCB มิ.ย./BIGC พ.ค./AYU พ.ค.):
- LCB มิ.ย. + BIGC พ.ค. = engine/ชีท gross ถูก.
- AYU พ.ค. = gross=net (ลอกยอด) — ถ้า finalize แล้วดู finance เดือน พ.ค. AYU cost จะต่ำกว่าจริง (เหมือนข้างบน).
