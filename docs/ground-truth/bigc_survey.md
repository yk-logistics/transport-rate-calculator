## 4. Pay Model (BIGC Site)

### สรุปโมเดล

**Per-Trip (ค่าเที่ยว) + Base Salary + Fuel Rebate**

1. **ค่าเที่ยว** — คิดต่อเที่ยว ตามเส้นทาง (ราคาต่อใบงาน บันทึกในชีทรายวัน) สะสมตลอดเดือน
2. **เงินเดือนฐาน (Base Salary)** — มีทุกคน แตกต่างกันตามคน (พบ: 1,800 / 2,100 / 7,500 / 8,100 / 8,400 / 9,000 บาท) — ไม่ใช่ fixed rate เดียว
3. **ค่าเรทน้ำมัน (Fuel Rebate/Penalty)** — คำนวณจากผลต่าง actual fuel rate (บาท/กม.) vs target rate กำหนด (3.8 บาท/กม.) คูณกับ km ที่วิ่งจริง → อาจเป็น + หรือ − ขึ้นกับพฤติกรรมการเติมน้ำมัน
4. **gross** = ค่าเที่ยว + เงินเดือน ± ค่าเรทน้ำมัน
5. **หัก** = ยอดเบิกล่วงหน้าสะสม (เงินเบิก/อุบัติเหตุ/ซ่อม) — ดึงจากชีท เงินหัก
6. **net** = gross − หัก
7. **ประกันสังคม**: มีชีทติดตามแยก (เงินประกันตน) — ฐาน 1,000 บาท/เดือน/คน บางคนคืนให้ในรอบจ่าย

## 7. สิ่งที่ยังไม่ชัด / Risk สำหรับ Onboarding

### UNKNOWN #1 (Critical): เงินเดือนฐาน (Base Salary) กำหนดอย่างไร?
ในรวม YK ตัวเลขฐานต่างกัน (1,800 / 2,100 / 7,500 / 8,100 / 8,400 / 9,000) ไม่ทราบว่า:
- ผูกกับ x/10 (วันทำงาน proportion) หรือ flat rate ต่อคน?
- มีตาราง grade/rate ที่ไหน หรือกำหนดในหัว?
- บุญชอบได้ 1,800 (1/10 day ratio) vs เกรียงไกรได้ 9,000 (10/10) — ดูเหมือน proportional แต่ยังไม่ยืนยัน

### UNKNOWN #2 (Critical): ค่าเที่ยว (per-trip rate) กำหนดจากอะไร?
ในชีทรายวัน ค่าเที่ยวต่อเส้นทางไม่ตรงกัน (เช่น 800, 600, 200, 500 บาท) — ไม่ชัดว่า:
- มีตารางราคาต่อ route code ไหม? (11209=Chantaburi=800บาท?)
- 2BigC vs 2++ vs 2BH คิดต่างกันอย่างไร?
- ลูกค้าอื่น (Oatside, Homepro, BH) ผสมอยู่ในยอดเดียว — ต้องแยก billing ออกจาก payroll ไหม?

### UNKNOWN #3: แบ็งค์ slot 7, 8 (บุญชอบ/พรศักดิ์) labeled "เงินประกันตน"
ทั้งสองคนได้รับเงิน label ว่า "เงินประกันตน" แต่ gross ของบุญชอบใน รวม YK = 5,076 บาท ≠ 5,986 ที่โอน (selectively มีการบวก 1,000 เข้า) — กลไก "-1000" flag ยังไม่ชัด

### UNKNOWN #4: plate สลับ (71-8001)
ธนวัฒน์ ออก 7/5/26, มานพ เริ่ม 4/4/26 ใช้รถคันเดียวกัน — ต้องรู้ว่าในเดือน May แถวใดเป็นของใคร (fuel rate sheet แยกเป็น มานพ แล้ว — OK แต่ต้องตรวจ daily)

### UNKNOWN #5: ตัวเลข CJ 323,278 บาท
ปรากฏทั้งใน 5.May และ 6.Jun แบ็งค์ sheet — เป็นตัวเลขคงที่ ไม่เปลี่ยนแปลง — ไม่ทราบความหมาย (อาจเป็น billing รวม CJ+YK หรือ fixed contract)
