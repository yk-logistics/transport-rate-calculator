**กฎโอ (2026-06-27):** น้ำมันที่เติม "ก่อนคนขับเริ่มวิ่งงานจริง" (รถจอด/ซ่อมช่วงรับรถใหม่) + "ถังเต็มถังแรกตอนเริ่มเหมา" (บริษัทออกให้) = **ไม่หักคนขับ**. วิธีดูถังเต็ม: ลิตรเป็นเศษ (เด็กปั๊มเติมเต็มตามจำนวนบาท เช่น 117.675 ล.) ต่างจากสั่งลิตรกลม (50/60/70/100). ขาออก/คืนรถ/ตัดรอบ: วัดน้ำมันเหลือ บริษัทซื้อคืน → คืนเงินคนขับ (ถ้าขับต่อไม่ออก/ไม่วัด=ไม่คืน).

**Feature (merged main + deployed server 2026-06-27):** โอเลือก **override รายบิล** (ไม่ auto-detect — กระทบเหมาทุกคน เสี่ยง). `FuelTxn.exclude_from_driver` bool default False (schema **v26**, `_ensure_column fueltxn`). Engine helpers `_sum_fuel_cost` + `_sum_fuel_cost_for_dates` เพิ่ม `.where(exclude_from_driver == False)` → กระทบ lcb_mao/lcb_mixed/ayu_self_fuel. **default False = เหมาทุกคน net เท่าเดิมเป๊ะ** (regression verified: 10 LCB drivers diff=0.0). UI: หน้า `/payroll/{run}/employee/{emp}` ตาราง FuelTxn ได้คอลัมน์ "หักคนขับ?" + ปุ่ม toggle (POST `/fuel/{id}/toggle-exclude` → recompute → redirect #fuel), บิลที่ติ๊กขีดฆ่า+สีจาง + สรุป "หักจริง X / ไม่หัก Y (N บิล)". Locked เมื่อ finalized. Guard: bill ต้อง driver_id ตรง (404 ถ้าไม่ใช่). 3 unit tests.
