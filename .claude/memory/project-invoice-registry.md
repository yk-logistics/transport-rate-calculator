# v52 ทะเบียนใบวางบิล + v53 ใบเสร็จ 3 สถานะ (deploy 12 ก.ค. 2026, commit 08931ea)

โอเคาะ 12ก.ค. ("จัดการแทนฉันเลย") — เปลี่ยนกติกาเดิมของ [[project-c2-invoice-builder]]
ที่ตั้งใจไม่เขียน DB: ตอนนี้**กดสร้างใบ → ประทับ invoice_no ลงเดลี่ทุกแถวที่เลือกอัตโนมัติ**

## กติกาที่ล็อกไว้ (อย่าทำพัง)
- แถวที่มีเลขใบ **อื่น** อยู่แล้ว → 400 ทั้งใบ ไม่เขียนอะไรเลย (ห้ามทับเงียบ) — จะย้ายใบต้อง "ถอนใบ" ก่อน
- ถอนใบ (void): ปลดเลขคืนจากเดลี่ทุกแถวของใบนั้น (เทียบด้วย parse_invoice_no ไม่ใช่ string ตรง เพราะช่องมีขยะท้าย เช่น '\t19/6/2026') — ใบ paid ถอนไม่ได้ ต้องย้อนสถานะก่อน
- สร้างเลขเดิมซ้ำหลัง void = ใบใหม่ (สถานะกลับ issued); ใบ paid สร้างซ้ำไม่ได้
- total_amount = Σ ทุกช่องเงินของแถว ณ ตอนสร้างใบ (price+charges+advance) — ไม่ recompute ทีหลัง
- due_date ว่างได้ (ไม่รู้เครดิตเทอม — โอ/ทีมมาเติมทีหลังใน dropdown อัปเดต)
- หน้า /billing/invoices + เมนู "เงิน" → 📒 ทะเบียนใบวางบิล; แถวเกิน due ไฮไลต์แดง

## v53 ใบเสร็จสดย่อย 3 สถานะ
- `PettyCashTxn.receipt_status`: have|none|waiting ('' = แถวเก่า ใช้ has_receipt ตามเดิม — ไม่ backfill)
- waiting → โผล่หน้ารอเคลียร์แม้ pending_amount=0 + ปุ่มเดียว "📄 ได้ใบเสร็จแล้ว" (→ have + has_receipt sync)
- ฟอร์มเปลี่ยน checkbox → radio 3 ทาง; ทางอื่นที่ยังส่ง checkbox เดิมทำงานต่อได้ (backward compat ใน petty_save)
