**BACKLOG เดิม — feature ทั่วไป ยังไม่เริ่ม (โอสั่งจดไว้ทำวันหลัง 2026-06-27).**

**ปัญหา:** เมื่อคนอื่นมาขับรถของคนเหมาชั่วคราว (เจ้าของลา/หยุด) ตามกติกาโอต้อง **วัดน้ำมันในถังตอน "ขึ้น" และตอน "ลง"** เพื่อคิดเงินน้ำมันให้ถูกคน — น้ำมันที่เจ้าของจ่ายไว้ก่อน คนมาขับใช้ไป ต้องคืน/หักให้ตรง. **ปัจจุบันระบบไม่มี mechanism นี้เลย** — ไม่มี field/record/note สำหรับ "น้ำมันเหลือตอนส่งมอบรถ" (ตรวจแล้ว: fueltxn.fill_type มีแค่ ''/credit, ไม่มี note วัด/เหลือ/คืน).

**ผลตอนนี้ (workaround):** ใช้หลัก "คนเติม = คนรับผิดชอบบิลนั้น" → ย้าย attribution บิลน้ำมันไปคนที่ขับ/เติมจริง (ดู [[project-fuel-exclude-from-driver]] เคส 8684 พัฒิยะ→สันติพงษ์, เคส 6802 นิพล→สุวิทย์). แต่ถ้าน้ำมันที่เจ้าของเติมไว้ก่อนถูกคนมาขับใช้ไป — คิดแยกเป๊ะไม่ได้เพราะไม่มีตัวเลขวัด.

**ถ้าจะทำ feature นี้ (ต้อง brainstorm + design ก่อน):**
- เพิ่มแนวคิด "วัดน้ำมัน handover" — record น้ำมันเหลือ(ลิตร/บาท) ตอนคนขับเปลี่ยน (ขึ้น/ลง)
- ผูกกับ pay engine: เจ้าของเหมาได้คืนน้ำมันที่เหลือตอนส่งมอบ, คนมาขับรับผิดชอบส่วนที่ใช้
- โยงกับกฎที่มีแล้ว: ถังเต็มแรก/ตัดรอบคืนน้ำมัน (ดู [[project-fuel-exclude-from-driver]] กฎโอเรื่องวัดน้ำมันคืนตอนตัดรอบ)
- เป็นงานเงิน → branch + TDD + regression ตามปกติ

**Why:** การไม่มีตัวเลขวัดทำให้เคสคนขับแทนรถเหมาต้องเดา/ใช้ workaround attribution แทนการคิดจริง. โออยากได้ความแม่นยำในอนาคตเมื่อมีเวลา.
