**GOTCHA พิมพ์ใน artifact (ยืนยันจากอาการจริง 6ก.ค.):** iframe sandbox ของ claude.ai บล็อก **print / window.open / download / แม้แต่ alert แบบเงียบหมด ไม่ throw สักอัน** และ Ctrl+P พิมพ์หน้าแม่ได้แค่ viewport เดียว — **พิมพ์ใน claude.ai ไม่ได้เด็ดขาด** → ปุ่มพิมพ์เช็ค `window.self !== window.top`: หน้าเดี่ยว (ไฟล์ในเครื่อง/MVP) = `window.print()` ตรง; ใน iframe = ลอง open→download แล้วโชว์**แบนเนอร์ในหน้า** (ช่องทางเดียวที่บล็อกไม่ได้) แนะนำเปิดไฟล์ในเครื่อง; ทางพิมพ์จริงตอนนี้ = ดับเบิลคลิกไฟล์ `wonder_sub_cost_2026.html` ในเครื่อง
