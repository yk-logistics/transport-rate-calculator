กติกาธุรกิจ "ที่ไม่เป็น logic เป๊ะ" ที่โอยืนยันด้วยตาเอง 2026-06-24 ตอนรีวิวรายงาน
[[project-lcb-daily-fuel-crosscheck]] วันที่ 12 มิ.ย. — จดไว้กันถาม/จับผิดปลอมซ้ำ:

1. **คนข้ามไซท์มาเติมที่ Caltex ได้** (สำคัญสุด). ตัวอย่าง: **71-5042 = คนไซท์ BIG-C**
   แต่บางทีมาเติมที่ปั๊ม Caltex (ซึ่งเป็นปั๊มของไซท์ LCB). ฉะนั้น "มีแจ้งเติมในกลุ่ม Caltex
   แต่ไม่มีแถวเดลี่ LCB วันนั้น" **ไม่ใช่ความผิดเสมอไป** — อาจเป็นรถไซท์อื่น. สิ่งที่ต้องทำคือ
   **ไปเช็คว่าไซท์ต้นทาง (เช่น BIG-C) จดยอดน้ำมันนี้ไหม** (กันน้ำมันตกหล่น/คิดซ้ำข้ามไซท์).
   → ปรับ tool: ก่อนเหมา fueled_no_daily ควรเช็คทะเบียนกับ "รถไซท์อื่น" ด้วย แล้วป้าย
   "cross-site (ตรวจไซท์ X)" แทนการป้ายว่าผิด.

2. **ทะเบียนพิมพ์ผิดในข้อความแจ้งเติมเกิดได้** เช่น **72-1200 = พิมพ์ผิดของ 72-1220**
   (ปกรณ์คันเดิม). ทะเบียน LCB จริงเดินเป็นชุด 72-12xx — เลขหลุดชุด/ไม่มีในทะเบียน fleet
   = น่าจะ typo. tool อาจ suggest "ทะเบียนใกล้เคียงที่มีจริง" ได้.

3. **ข้อความ "อ่านไม่ออก" (unparseable) ส่วนใหญ่ไม่ใช่ปัญหา** — เป็นการคุยกับปั๊มเรื่องเติมผิด
   /สอบถามยอด ไม่ใช่แจ้งเติม. ฉะนั้น unparseable = ความสำคัญต่ำสุด (โชว์ท้ายสุด/ยุบได้)
   ไม่ต้องเด่น.

ภาพรวมที่ได้: ปั๊ม Caltex จุกกะเฌอ/ปิ่นทอง/เต็กย้ง เป็นปั๊มที่รถ YK หลายไซท์มาเติม ไม่ใช่ LCB
ล้วน. การ cross-check จึงต้องคิดแบบ "รถคันนี้ของไซท์ไหน วันนั้นมีงานไซท์ไหน" ไม่ใช่ผูกกับ LCB
อย่างเดียว. (โยงงานเงินเดือนข้ามไซท์ → กฎเงิน "ห้ามเดา cross-site" ใน CLAUDE.md.)
