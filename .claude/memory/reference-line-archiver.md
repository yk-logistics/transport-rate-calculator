Service เก็บข้อความ+รูปจากกลุ่ม LINE (แก้ปัญหารูปหมดอายุ/ค้นไม่เจอ; ต่อยอด MVP ภายหลัง) อยู่ที่ `ProjectYK_System/line_archiver/` — **service แยกขาดจากแอป MVP** (port 8020 ไม่ใช่ 8010, DB แยก `line_archive.db`, ไม่แตะ `app/main.py`/`app.db`).

**สถาปัตยกรรม:** LINE Messaging API webhook → archiver.py (เก็บ DB + ดาวน์โหลดไฟล์ลง `line_media/`) → forward Discord (auto-create channel ต่อกลุ่ม, bot token). บันทึก DB ก่อนเสมอ แล้ว retry forward ทุก 5 นาที (Discord ล่มข้อมูลไม่หาย). คุย REST ตรงด้วย httpx (ไม่ใช้ SDK). ใช้ venv เดิมของ `app/`.

**เปิดใช้:** ดับเบิลคลิก `start_all.bat` (เปิดบอท + cloudflare tunnel). ดู `SETUP_CHECKLIST.md` (สมัคร LINE/Discord) + `SERVER_GUIDE.md` (รันบน server + named tunnel). `.env` มี 4 ค่า (LINE secret/token, Discord bot token/guild id) — ไม่อยู่ใน git.

**Tunnel:** ใช้ Cloudflare **named tunnel `yk-line`** ผ่าน **`line.yklogistics.uk`** (URL คงที่, bandwidth ไม่จำกัด, 24 ชม.). tunnel-id `741eef82-38c6-4243-be04-a4b4e287a303`. **ข้อสรุป:** ngrok free ไม่พอ (1GB/เดือน + ตัด 2 ชม.); Cloudflare partial-setup ต้อง Business $200/เดือน. เดิมจะใช้ yklogistics.com แต่มีอีเมลจริง (ห้ามล่ม) → **ซื้อโดเมนใหม่ `yklogistics.uk` ($5.3/ปี Cloudflare Registrar) แยกจากอีเมล**. (DNS .com เก่าที่ [[reference-yklogistics-dns]] เลิกใช้แล้ว.)

**Tunnel credential backup (2026-06-14):** dev copy ของ tunnel credential เก็บที่ `line_archiver/cloudflared_home/` (3 ไฟล์: `741eef82-...json` + `cert.pem` + `config.yml`) — **gitignored ไม่อยู่ใน git** จึงไม่ติดมากับ clone. ถ้าย้าย/restore เครื่อง dev ต้องเอา 3 ไฟล์นี้ไปด้วยมือ (ไม่งั้น recreate tunnel `yk-line` ไม่ได้). เดิมไฟล์ชุดนี้ลอยอยู่ใน `Desktop\YK_LINE_TO_SERVER` (ลบทิ้งแล้ว — โค้ดที่เหลือซ้ำ+เก่ากว่า repo). [[reference-ssh-to-yk-machine]] ฝั่ง server มีชุดของตัวเองที่ `~\.cloudflared`.

**AUTO-START via NSSM services (FINAL setup 2026-06-13):** บอท+tunnel รันเป็น **Windows service ผ่าน NSSM** บน server (Start=Automatic, self-heal). คือคำตอบสำหรับ **"เปิด server ระบบ LINE archiver"** — เครื่องบูตขึ้นมาก็รันเอง ไม่ต้อง login, process ดับเองก็กู้เองในวินาที:
- `nssm.exe` อยู่ที่ `C:\Users\yklog\AppData\Local\Microsoft\WinGet\Links\nssm.exe` (ลงด้วย `winget install NSSM.NSSM`).
- **`YKLineBot`** = `.venv\Scripts\python.exe main.py` (cwd `C:\Users\yklog\YK_LINE_ARCHIVER`, port 8020). AppExit=Restart, RestartDelay 3s. log → `svc_bot.out/err.log`.
- **`YKLineTunnel`** = `cloudflared.exe tunnel --config C:\Users\yklog\.cloudflared\config.yml run yk-line`. log → `svc_tunnel.out/err.log`.
- **รันเป็น LocalSystem (ไม่ต้อง password!)** — ได้เพราะทุก path เป็น absolute. **กุญแจ:** cloudflared default หา config ที่ `~\.cloudflared` ของ user ที่รัน → LocalSystem จะหาที่ systemprofile (ว่าง) ต้องใส่ `--config <abs path>` เสมอ. config.yml มี `credentials-file` เป็น abs path อยู่แล้ว.
- คุม: `nssm start/stop/restart YKLineBot|YKLineTunnel` หรือ `Get-Service YKLineBot,YKLineTunnel`. แก้ config: `nssm edit <svc>` (GUI) หรือ `nssm set <svc> <param>`.
- **Health-poll + Discord alert:** Scheduled Task **`YK_LINE_HEALTHPOLL`** (SYSTEM, ทุก 5 นาที) รัน `health_poll.py` — เช็ก local `127.0.0.1:8020/health` + public `line.yklogistics.uk/health`; เด้ง alert เข้า Discord channel **`line-archiver-alerts`** (id 1515399700067647609, auto-create) **เฉพาะตอนเปลี่ยนสถานะ** (ok→down, down→ok) ไม่ spam. state ใน `health_state.json`. จับเคส "tunnel หลุดแต่ bot ยังอยู่" ที่ NSSM self-heal มองไม่เห็น (service ยังรัน). **ห้าม print emoji ตรงๆ บน Windows console (cp874 crash)** — ส่งเข้า Discord ได้ปกติ แต่ readback ด้วย python print ต้องระวัง.
- **เดิม:** Scheduled Task `YK_LINE_ARCHIVER` (AtLogOn, autostart_launch.bat) — **disable แล้ว** (NSSM แทน). ห้ามเปิดคู่กัน (สตาร์ตซ้อน/port ชน).
- **บทเรียน:** สตาร์ต process ผ่าน SSH session ตรงๆ (Start-Process) **ไม่รอด** — ตายเมื่อ SSH ปิด (job object teardown). ต้องผ่าน service/scheduled-task. **Root cause ที่ดับ 2026-06-13:** Windows Update รีบูตเครื่อง 00:24 ลง service pack แล้วไม่มี autostart (เดิมเปิดด้วยมือ START.bat) บอทดับเงียบตั้งแต่ 00:14 (อาการ /health → Cloudflare 1033/530, ไม่มี python/cloudflared รัน). ตอนนี้แก้ถาวรด้วย NSSM แล้ว.

**สถานะ operational (2026-06-13):** บอทเข้ากลุ่ม LINE เกือบทุกกลุ่มแล้ว, ดึงข้อความ/รูป/ไฟล์ลงเครื่อง + forward เข้า Discord ได้ราบลื่น (pipeline นิ่ง). **Remote control ผ่าน Tailscale:** สั่งงาน/จัดการบอทบนเครื่อง server ผ่าน Tailscale ได้แล้ว (นอกเหนือจาก Cloudflare named tunnel ที่ใช้รับ LINE webhook อย่างเดียว — คนละทาง: Cloudflare = inbound webhook, Tailscale = admin/SSH เข้า server). ดู [[reference-ssh-to-yk-machine]] (passwordless SSH Home→YK, แผน Tailscale สำหรับ off-LAN).

**DEPLOY บน Server เสร็จแล้ว (2026-06-12):** รันบนเครื่อง server (user `yklog`, Python 3.14.6 — archiver lib รอด 3.14). ติดตั้งด้วยชุด `installer/` (BUILD_USB.bat ประกอบ → INSTALL.bat ลง → START.bat รัน). บอทเข้ากลุ่มจริง **40+ กลุ่ม** channel auto-create ครบ; `https://line.yklogistics.uk/health` = ok จากภายนอก. **บทเรียน installer (แก้แล้วใน git):** (1) .bat comment/echo ต้อง ASCII ล้วน — ภาษาไทย UTF-8 ทำ cmd พังเพราะอ่านด้วย ANSI codepage; (2) path `Program Files (x86)` มีวงเล็บ ห้าม echo `%VAR%` ใน `if(...)` block (ปิด block ก่อนเวลา → แว็บหาย) ใช้ `goto :label` แทน; (3) `where python` เจอ Microsoft Store alias → ต้อง `python --version` จริง + ปิด app execution alias; (4) config.yml ห้ามก็อปข้ามเครื่อง (ฝัง `C:\Users\guole\` ตายตัว) — INSTALL.bat generate ใหม่จาก `%USERPROFILE%`; (5) Root cause webhook เงียบ = ลืมเปิด "Use webhook" ใน LINE console (Verify ผ่านแม้ toggle ปิด). **กฎเปิดใช้:** tunnel `yk-line` รันได้ทีละเครื่อง — ห้ามเปิดค้างทั้ง dev+server พร้อมกัน.
