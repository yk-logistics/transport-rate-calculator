**ชื่อเรียก: โอพูด "แพลน MVP" / "แพลนงาน MVP" = ไฟล์นี้** (`ProjectYK_System/docs/MASTER_PLAN_2026-07.md`)

**กติกาคีย์ราคาลูกค้า KB (โอยืนยัน 3ก.ค.เช้า): คนคีย์เดลี่ใส่ "ราคาที่เราต้องได้จริง" (net หลัง KB) ไม่ใช่ราคาวางบิลเต็ม — ระบบต้องรู้กติกานี้ตอน import; KB เติมทีหลังอัตโนมัติจากไฟล์อินวอย (งานเฟส C); ไม่เพิ่มคอลัมน์ KB ในชีท**

**2 ก.ค. 2026 ~20:00 โอเล่า flow ธุรกิจทั้งเส้น** (เสนอราคา→รับงาน/ปฏิทินรถ→จ่ายงาน→เดลี่→หลักฐานคนขับ→วางบิล→รอรับเงิน→ใบเสร็จ/ใบหัก→KB→สดย่อย→เงินเดือน→กำไร/งบดุล→ซ่อม) แล้วสั่งวางแผนเจาะลึก+ประเมินวันเสร็จ ให้ Fable คิดตอนนี้แล้วโมเดลเด็กทำต่อได้

**ผลลัพธ์ = `ProjectYK_System/docs/MASTER_PLAN_2026-07.md`** (commit แล้ว) สาระ:
- สถานะรวม **62%** — ระบบมี 231 routes/12 โมดูล "อวัยวะครบแต่ยังไม่ต่อกัน" จุดขาดคือหัว flow (เสนอราคา/ปฏิทินรถ) + เอกสารวางบิล/ใบเสร็จ
- **5 เฟส ~14 วันทำ (~3 สัปดาห์):** A ปิดวงเงิน 2วัน (KB CY + ใบเสร็จ/ใบหัก + AR sync sheet + BigC ปิดรอบ) → B รับงาน 4วัน (ย้ายเครื่องคิดเรท GitHub Pages เข้า /quote + ตาราง Quotation + ผูกราคาเข้าเดลี่ + **ปฏิทินกำลังรถ**) → C วางบิล 3วัน (เช็คครบ + ออกใบวางบิลตามฟอร์มลูกค้า + Oatside import) → D ผู้บริหาร 3วัน (เติมราคาเดลี่ทุกไซต์ + เงินหมุน/งบดุลรวมหนี้ส่วนตัว/OD/บัตร + ต้นทุนต่อคัน) → E สนาม 2วัน (PWA เช็คอิน+รูปตู้ 4 ด้าน + น้ำมันผิดปกติ)
- **ตัด:** TMS ติดตามสด, API GPS (ดูเว็บ vendor ฟรี), แอพคนขับ push (ใช้ไลน์+PWA เดิม)
- **5 คำถามรอโอ:** ทาง B ของ KB CY + 7 แถวราคาชน / เลือก 3 ลูกค้าแรกออกใบวางบิล (เสนอ CY,NHL,KLN) / นิยามรถว่าง+ที่บันทึกคนขับลา / BigC ค้าง (เกศศักดิ์/ธนวัฒน์/ภาษี) / เครื่องคิดเรทตัวจริงคือ transport_rate_calculator.html ใช่ไหม
- ปล่อยใช้เป็นช่วง: จบเฟส A = วงเงินใช้จริง 100% ไม่ต้องรอเฟสอื่น
