โอสั่ง 2 ก.ค. 2026 (แก้ความเข้าใจรอบแรกของผม): ประเด็นคือ **การส่งต่องาน** ไม่ใช่การเลี่ยง AI —
"เวลาคุณทำงาน แล้วอนาคตฉันไม่ได้ใช้คุณต่อ อยากให้เขียนข้อความไว้ให้เด็กๆ (Model ต่ำกว่า) สามารถทำต่อได้
เรื่องโปรแกรมไม่พึ่ง AI อันนั้นไม่เป็นไร อนาคตอาจจะสั่งผ่าน AI ก็ได้อยู่"

**Why:** โอกลัววันหนึ่งไม่ได้ใช้โมเดลใหญ่ (Fable/Opus) แล้วงานสะดุด เพราะความรู้ค้างอยู่ในหัว AI ตัวเดิม —
ต้องการให้ Haiku/Sonnet/Qwen หรือใครก็ตามรับช่วงต่อได้จากเอกสารที่ทิ้งไว้ ส่วนการสั่งงานผ่าน AI ยังโอเค ไม่ต้องเลี่ยง

**How to apply (ทุกงานที่มีสาระ ไม่ใช่แค่งานใหญ่):**
1. เขียน **runbook/บันทึกส่งต่อ** สำหรับ "คนที่เก่งน้อยกว่าเรา" — สะกดทุกขั้น: คำสั่งรันเป๊ะๆ copy-paste ได้,
   ตัวอย่าง input/output จริง, สูตรธุรกิจพร้อมเลขตัวอย่างที่โอยืนยันแล้ว, gotcha ที่เคยเจอ — ห้ามเขียนแบบต้องอนุมานเอง
2. ที่เก็บ: docs/ ใน repo (เช่น docs/KB_PAYOUT_RUNBOOK.md เป็นตัวอย่างแบบที่ถูก) + memory topic file ชี้ไปหา
3. สูตรเงิน/กติกาธุรกิจ ต้องอยู่ในโค้ด (constants+docstring) หรือเอกสาร — ไม่ใช่อยู่แค่ในบริบทแชท
4. เวลาปิดงานใหญ่ ถามตัวเอง: "ถ้าพรุ่งนี้ Haiku มารับช่วง มันรู้ไหมว่าต้องทำอะไรต่อ จากไฟล์ที่ทิ้งไว้?" ถ้าไม่ = เขียนเพิ่ม
5. ฟีเจอร์จะเป็นหน้าในระบบหรือ workflow ผ่าน AI ก็ได้ทั้งคู่ — โอไม่ติด
