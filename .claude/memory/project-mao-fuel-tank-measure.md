**โอบอกให้จำไว้ใช้อนาคต — กฎคิดน้ำมัน "คนเหมา" 2 แบบ:**

**แบบ A — ไม่ได้เติมเต็มถังตอนขึ้น (วัดน้ำมันในถัง):**
- เริ่มเหมา: **วัดน้ำมันในถัง → หักคนขับเลย** ตามลิตรที่มีในถัง (บริษัทจ่ายน้ำมันนั้นมาก่อน คนขับรับช่วงไป)
- ตัดรอบ/ลงรถ/สลับรถ: วัดถัง → **บริษัทซื้อคืน** (คืนเงินคนขับตามน้ำมันที่เหลือ)
- กลับมาขึ้นอีก: วัดอีก → หักอีก (วน)
- ทำงานต่อเนื่องไม่เปลี่ยนมือ: ไม่ต้องวัด/ซื้อคืนไปมาก็ได้

**แบบ B — เติมเต็มถังตอนขึ้น:**
- ถังแรก(เติมเต็ม) **ไม่หัก** เลย
- เปลี่ยนคน/เปลี่ยนรถ/ลงรถ: ต้อง**เติมคืนเต็มถัง** = คิดน้ำมันที่คนขับใช้ไปทั้งหมด

**วิธีคิดเงิน "หักน้ำมันในถัง":** ลิตรในถัง × **ราคา/ลิตรของบิลล่าสุดวันนั้น** (โอยืนยัน 2026-06-28).
**ลงระบบยังไง:** สร้าง **FuelTxn บิลพิเศษต่อคน** `source='mao_tank_measure'`, `fill_type='tank_measure'`, ผูก driver_id, ลงวันที่เริ่มเหมา, `exclude_from_driver=False` (ให้หักจริง). ระบบยังไม่มี field/ปุ่มเฉพาะสำหรับ "วัดถัง" — ใช้บิล FuelTxn เป็น mechanism (ตรวจย้อน/ลบได้). [[project-fuel-handover-measure-backlog]] = feature จริงที่ยังไม่ทำ.

**สำคัญ mixed:** lcb_mixed หักน้ำมันเฉพาะวัน mao-phase (`_sum_fuel_cost_for_dates`, mao days + idle-in-mao). บิลวัดถังต้องลงวันที่เริ่มเหมา = วัน mao → ถึงจะถูกนับ. ไม่ double-count กับบิลที่คนขับปั๊มช่วงเหมา (คนละก้อน: ถังที่รับช่วงมา vs ที่เติมเอง).
