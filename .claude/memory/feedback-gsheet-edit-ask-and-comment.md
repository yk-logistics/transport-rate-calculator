โอสั่ง 30มิ.ย. (หลังผมแก้ gsheet ผิด — เปลี่ยนชื่อ/ทะเบียนทั้งแถวเที่ยวของเรวัตรเป็นวัชรนล ทำให้งานเที่ยวสลับเจ้าของในชีต): **ห้ามแก้ Google Sheet เองโดยพลการ**.

1. **ถามก่อนทุกครั้ง** ก่อนแก้ gsheet — ไม่ใช่แก้แล้วค่อยบอก. เสนอว่าจะแก้แถวไหน ช่องไหน เป็นอะไร แล้วรอ ok.
2. **ใส่ comment (Google Sheets note) ทุกช่องที่เปลี่ยน** — ระบุค่าเดิม→ค่าใหม่ + เหตุผล เพื่อให้คน**ตรวจสอบ/ย้อนได้** (กันพลาด). ไม่ใช่แค่ต่อ note ในเซลล์ข้อความ — ใช้ cell note/comment.

**Why:** ชีตเป็น ground truth ที่คนคีย์/ตรวจด้วยมือ. ผมแก้เองพลาด (gsheet น้ำมัน+เที่ยวอยู่แถวเดียวกัน → เปลี่ยนชื่อทั้งแถว = ย้ายงานเที่ยวไปด้วย). ถ้าแก้เงียบ คนตามไม่ทันว่าอะไรเปลี่ยน.

**How to apply:** ก่อนแตะ gspread `update_cell`/`update` → สรุปให้โอ (แถว/ช่อง/เดิม→ใหม่) ขอ ok ก่อน; หลังแก้ใส่ note ทุกเซลล์ที่แตะ (`ws.insert_note` / batch note ผ่าน Sheets API) ว่า "เดิม X → ใหม่ Y (เหตุผล, โดย Claude วันที่)". เคสที่เจอ: [[project-fuel-move-0556-0560]] (ผมแก้ B/D ทั้งแถว r753/r754 = พลาด, ต้องคืน). related: [[reference-google-sheets-access]]
