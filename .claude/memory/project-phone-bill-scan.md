# สแกนหาบิลในมือถือโอ → กล่องบิลรอคัด (เริ่ม 10 ก.ค. 2026)

โอหารูปบิล/ใบเสร็จในมือถือไม่เจอ ไม่รู้ถ่ายเมื่อไหร่ → ก็อปรูปทั้งเครื่อง (iPhone ผ่าน MTP)
มาคัดบนเครื่อง Dev แล้วส่งเฉพาะบิลเข้า [[project-maint-bill-lines-ocr]] กล่องบิลรอคัด v51 บน server

## ที่อยู่ของ (โอสั่งให้ทุกอย่างรวมที่เดียว ย้ายเครื่อง/format ง่าย)
- `PhoneBillScan/` ในราก repo Project YK — **gitignored ทั้งโฟลเดอร์** (.gitignore:209) ห้าม commit รูปส่วนตัว
- `raw/<YYYYMM_a>/` รูปต้นฉบับ 34 เดือน 9,938 ไฟล์ (ธ.ค.2023–ก.ค.2026, HEIC 55%/JPG 39%/PNG 6%)
- `thumbs/` รูปย่อ 256px · `features.csv` คะแนนความเป็นเอกสาร · `s<เดือน>_NN.jpg` contact sheets + `s<เดือน>_map.csv` (cell→path)
- `scan_features.py` (ย่อ+ให้คะแนน) · `make_sheets.py` (สร้างแผ่น) · `triage_sheets.ps1` (Haiku กวาด) — ทุกตัว path-independent
- `pylib/` = pillow-heif แยกจาก venv แอป (ถอดรหัส HEIC)

## Gotcha ที่เจอจริง
- **ยิง `claude -p` เป็นร้อยรอบ = ระวังโควต้า+overhead**: ① เรียกจากรากโปรเจกต์ = ทุก call แบก CLAUDE.md+memory ทั้ง repo (หลายหมื่น token/call) — ต้อง cd ไปโฟลเดอร์เปล่าก่อน ② มัดหลายรูป/call ประหยัด system prompt ③ เจอ "session limit · resets 9pm" ตอบทุก call เงียบๆ — สคริปต์ต้อง regex จับแล้วหยุด+resume ได้ (รอบแรกเผา 5 ชม.กับ error 235 แผ่น)
- **MTP เชื่อไม่ได้เรื่องจำนวนไฟล์**: โฟลเดอร์เดียวตอบ 592→0→241→592 คนละจังหวะ — สคริปต์ก็อปต้องรันซ้ำท้ายรอบ (resumable, skip เดือนครบ) เพื่อเก็บตกเดือนที่โดนตอบ "0"
- iPhone ต้องปลดล็อก+Trust ก่อน MTP เห็นของ; ก็อป ~10k ไฟล์ใช้ ~25 นาที (เร็วกว่าที่คาดมาก)
- ตัวกรอง "กระดาษ" ต้องรับกระดาษสี (สำเนาเหลือง/เขียว): V>0.50, sat<0.45 — sat<0.30 ทำบิลสีตกท้ายตาราง
- **Haiku อ่าน contact sheet (42 ช่อง/แผ่น, cell 170px) จับบิลได้ recall 100%** (พิสูจน์กับ ก.ค.2026: 23/23) แต่ precision ต่ำ (เหมาสลิปโอน/สกรีนช็อตมาด้วย) → ตัวใหญ่ตรวจตาซ้ำเฉพาะช่องที่ชี้; prompt แบบ 2 ถัง (paper/screen) แม่นขึ้นแต่ **ทำบิลหลุด 1 ใบ — ห้ามใช้**

## Worker OCR บน server (สร้าง 12ก.ค. — ใช้ซ้ำได้)
- **Scheduled task `YK_BILL_QUEUE_DRAIN` (SYSTEM)** รัน `app/kick_bill_queue.py` = เรียก `main._bill_inbox_pass()` ตรง — ระบายคิวโดยไม่ต้องรอใครเปิดหน้า
- **Gotcha ที่เจ็บจริง 3 ชั้น:** ① claude CLI บน server ล็อกอินผ่าน **OAuth token ใน start_mvp.bat** (YK_CLAUDE_EXE + CLAUDE_CODE_OAUTH_TOKEN + YK_CLAUDE_CONFIG) — โปรเซสอื่นต้องดูด env จาก bat นี้ ไม่งั้น "Not logged in"/"ยังไม่ได้ติดตั้ง" ② รันเป็น yklog ไม่ได้ (claude ของ yklog ไม่ได้ล็อกอิน) ต้องเป็น task SYSTEM ③ task SYSTEM เริ่มที่ System32 → **ต้อง os.chdir(app) ก่อน import main** ไม่งั้น sqlite:app.db ชี้ผิดที่
- `requeue_and_kick.py` = พี่เลี้ยง: flip failed ที่ retryable (limit/timeout/Not logged in/ยังไม่ได้ติดตั้ง) → pending + ปลุก task ถ้า worker ตาย — ผมรันวนทุก 30 นาทีจากเครื่อง Dev คืน 12ก.ค.

## กติกาอ่านบิล (โอสอน 11 ก.ค.)
- **IRISO ELECTRONICS = บิลฝั่งลูกค้า (งานขนส่งที่เราไปวางบิลเขา) — ไม่เอาเข้ากล่องบิลซ่อม** ถอน 12 ใบ (BillInbox 220-231, มิ.ย. 2026 IMG_4976-4987) ออกแล้ว 11 ก.ค.; สแกนรอบหน้าเจอฟอร์มเขียวต่อเนื่องหัว IRISO ให้ข้ามเลย
- **โรงพยาบาลบางโพ = เอกสารส่วนตัว/HR ไม่ใช่บิลซ่อม** — ถอนแล้ว 2 ใบ (237 ใบรับรองแพทย์, 238 บิลค่ารักษา); เจอชื่อโรงพยาบาลใน OCR ให้ทิ้ง
- **ทะเบียนรถในบิลมักเขียนแค่เลขท้าย**: "8003" = 71-8003 — เดารหัสนำหน้า 71- ก่อน แล้วเทียบกับตาราง vehicle
- **บิลถ่ายไว้จำนวนมากถูกคีย์ผ่านชีท RM History แล้ว** — พิสูจน์จริง 1 เคส: บิลไทร์มาร์ท 30/9/68 (ยาง WESTLAKE AZ599×2 71-8000) = M005828 ในระบบ (คีย์ 1/10/68, 12,000 บาท) — วันที่ในชีทอาจคลาดจากบิล 1-2 วัน; ก่อนบันทึกบิลเก่าให้เช็ค maintrecord รถเดียวกัน ±ไม่กี่วัน + ยอด/รายการตรงกันก่อนเสมอ
- ใบบันทึกบริการร้านยาง (ไทร์มาร์ท/ADVANTAGE) ไม่มีราคาในใบ — ราคาต้องหาจากชีทหรือถามโอ
