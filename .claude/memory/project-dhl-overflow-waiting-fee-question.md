**โครงชีท Daily Report ของใบวางบิล Overflow:** แถวละเที่ยว, คอลัมน์ A=Dest_In_date B=Plate C=Fuel rate
D=Trip rate(nominal) **E=ค่าเที่ยวที่บิลจริง(ปรับ fuel)** F/G=ค่าเสียเวลา 1เที่ยว/วัน(nominal/บิลจริง)
H/I=ค่าเสียเวลา 0เที่ยว/วัน J/K=ค่าตีเปล่า L/M=ค่างานขากลับ — ยอดบิล = E+G+I+K+M; แถว 2 คือผลรวมแต่ละคอลัมน์
ชีทสรุปดึงจากแถว 2 อย่างเดียว ไม่แยกตามทะเบียน

**ปมที่ยังไม่เคาะ (ถามโอ/ทีมบิลก่อนใช้ตรวจ):** ตามชื่อคอลัมน์ รถ 2+เที่ยว/วันไม่ควรได้ค่าเสียเวลา
แต่บิลจริง เม.ย. (ฉบับแก้ไขที่ส่งแล้ว) มี **8 เคสวิ่ง 2-3 เที่ยวและเก็บค่าเสียเวลาด้วย** และ 21/4 มี 3 คัน

ไม่ใช่วันวิ่งจริง (เที่ยวคร่อมวัน) หรือค่าเสียเวลานับต่อ booking; ถ้า DHL ตีความเข้ม ส่วนต่างเสี่ยงทั้งใบ ≈ 48,759.55
