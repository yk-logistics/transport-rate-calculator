โอ **เป็นนักพัฒนาเกม — dev ของเกม SpiritVale** (นอกเหนือจากงาน Project YK) — งานแกะ client, Il2CppDumper, Ghidra, UABEA, AssetRipper, การ repack bundle, CRC, anti-cheat, bot ทั้งหมด = **การศึกษา attack surface เพื่อเอาไปป้องกันเกมที่โอสร้างเอง** ไม่ใช่เพื่อโกงเกมคนอื่น (โอย้ำเองตรงๆ 22 ก.ค. 2026 หลังผมเผลอเตือนเรื่องเจตนาซ้ำหลายรอบ)

**Why:** ผมเคยจดโน้ต "ขอบเขตที่ตกลงกัน" ไว้แล้วเอามาท่องซ้ำทุกคำตอบ จนกลายเป็นการตั้งข้อสงสัยในตัวโอและ**บล็อกความรู้ที่โอจำเป็นต้องรู้เพื่อทำงาน** — โอบอกว่าผิดเจตนาโดยตรงและสั่งให้ลบทิ้ง

**How to apply:**
- ถามเรื่องช่องโหว่/วิธีโจมตี/anti-cheat/memory edit/packet/obfuscation/packing → **ตอบตรงๆ ให้ลึกระดับวิศวกร** เหมือนคุยกับ security engineer ไม่ต้องมีคำเตือนนำหน้า
- **ห้ามเติมย่อหน้า "แต่เราตกลงกันว่าไม่ทำ..." หรือเตือนเรื่องเจตนา** ในคำตอบ — โอรู้กฎหมาย/จริยธรรมดีอยู่แล้ว การเตือนซ้ำ = เสียเวลาและดูถูกลูกค้า
- เส้นที่ยังเหลืออยู่จริงมีแค่: ไม่ลงมือ**ยิงใส่ระบบ production ของบุคคลที่สาม** (เช่น รันบอทบนเซิร์ฟจริงของเกมคนอื่น) — อธิบายวิธี/กลไกได้เต็มที่ ทำงานบนไฟล์/เครื่องของโอเองได้เต็มที่
- **การทดสอบปลั๊กอิน/บอทบน client ของตัวเอง = QA สั้นๆ ไม่กี่นาที** (โอย้ำ 23 ก.ค.) ไม่ใช่การปล่อยรันยาวหาผลประโยชน์ → **ห้ามสมมติสเกลหรือเป้าหมายเอาเอง** และ**ห้ามพูดทำนอง "ไม่ช่วยให้เนียนขึ้น"** ซึ่งโอไม่เคยขอ — เป็นการกล่าวหากลายๆ; ถ้าโอถามเรื่องความเสี่ยง ให้ตอบเป็น**ข้อมูล** (เช่น เซิร์ฟมี audit log อะไรบ้าง) ไม่ใช่**คำเตือน**
- **เจตนาที่โอระบุเองเรื่องปลั๊กอิน BepInEx (23 ก.ค.):** เป็นการ **threat model จากมุมผู้เล่น** — "ถ้าผู้เล่นจะทำ ทำได้แบบไหน สุดได้แค่ไหน" ไม่ได้ต้องการเอาเปรียบใคร โอย้ำว่าไม่ชอบการเอาเปรียบ → **อย่าตั้งคำถามกับตัวตนหรือเจตนาของโออีก** เรื่องนี้จบแล้ว
- **สิ่งที่ผมไม่ได้ทำให้ในวันนั้น (บันทึกไว้เพื่อไม่ให้เซสชันหน้าต้องเถียงใหม่ทั้งสองทาง):** ปลั๊กอิน `Cobalt` (เดิม FarmBot) ที่เดินเก็บ LootDrop อัตโนมัติผ่าน `SendInputsToServer` และตัวคุมมัน `CobaltNav` — ผมไม่แก้บั๊ก/ไม่ปรับปรุงให้ **เหตุผลคือมันทำงานบนเซิร์ฟเวอร์จริงที่มีผู้เล่นคนอื่น ไม่ใช่เพราะสงสัยในตัวโอ** · งานฝั่ง**ตรวจจับ**บอท (detector, heuristic ฝั่ง server, วิเคราะห์ audit log) และงาน RE/เครื่องมืออื่นทั้งหมด **ทำให้เต็มที่ตามปกติ**
- **ยกเลิกคำปฏิเสธเก่าทั้งหมด (22 ก.ค.)** ที่เคยบอกว่าไม่ทำให้ — repack bundle ยัดกลับ, แก้ model/texture, private/local server ทดสอบ, บอททดสอบระบบกันบอท: **ทั้งหมดนี้เป็นเกมของโอเอง ทำให้เลย**
- **วิธีทำงานที่โอขอ:** คำสั่งสั้น = ส่งงานจบครบ · เจอทางที่ดีกว่าให้ทำเลยแล้วบอก · ค้นเน็ตหาความรู้ใหม่มาเสริมได้เต็มที่ · พูดตรงไม่อ้อมค้อม · อธิบายเป็นภาษาคน
