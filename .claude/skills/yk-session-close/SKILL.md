# ปิดเซสชัน Project YK — สมองถาวร 3 ที่ + ส่งไม้

ความรู้ที่ไม่ได้จด = ตายพร้อมเซสชัน ทำตามลำดับ:

## 1. PLAN_STATUS + docs ขึ้น server

- อัปเดต `ProjectYK_System/docs/PLAN_STATUS.json` (% + สถานะงานที่เปลี่ยน)
- scp docs 3 ไฟล์ (PLAN_STATUS.json, MASTER_PLAN_2026-07.md, MVP_TASK_SPECS.md) ขึ้น `YK_MVP/docs/` บน server — หน้า /admin/plan อ่านจากไฟล์บนนั้น

## 2. CHANGELOG

- เพิ่ม/เติมหัวข้อ `## YYYY-MM-DD` วันนี้ใน `ProjectYK_System/CHANGELOG_MASTER.md`
- นโยบาย: อ่าน/สนใจแค่ **3 หัวข้อ `##` ล่าสุด** (ดู docs/CHANGELOG_POLICY.md) — เก่ากว่านั้นย้ายไป ARCHIVE ได้

## 3. Memory

- จดทุก gotcha / ข้อสมมติ / การตัดสินใจ ที่ยังไม่ได้จดระหว่างทาง ลง `.claude/memory/` (1 ไฟล์ = 1 เรื่อง)
- อัปเดตบรรทัด index ใน `MEMORY.md` — เรื่องที่สถานะเปลี่ยน (เช่น "รอ X" → "เสร็จ") ต้องแก้บรรทัดเดิม ไม่ใช่เพิ่มซ้ำ
- แปลงวันที่สัมพัทธ์ ("พรุ่งนี้") เป็นวันที่จริงเสมอ

## 4. งานค้าง = จดแบบรอ trigger

ทุกงานที่ยังไม่จบ จดเป็นตาราง: **รอสัญญาณอะไร | เมื่อได้สัญญาณ ทำตามไฟล์ไหน** ลงใน `docs/HANDOFF_FABLE_TO_OPUS_*.md` **ตัววันที่ใหม่สุด** (เพิ่มหมวดใหม่ได้ อย่าสร้างไฟล์ซ้ำถ้าฉบับวันนี้มีแล้ว) — ห้ามจดแค่ "ยังไม่เสร็จ"

## 5. เช็คสุขภาพก่อนลุก

- [ ] `git branch --show-current` — ถูก branch, งานที่ตั้งใจ commit แล้ว commit ครบ (stage เฉพาะ path ห้าม `git add -A`)
- [ ] แอปยังรันได้: `curl https://app.yklogistics.uk/health` = 200 (ถ้าแตะ server) / start.bat (ถ้าแตะ local)
- [ ] ไม่มีไฟล์ scratch/ทดลองหลงอยู่ใน repo

## 6. รายงานโอ

สั้น ภาษาคน ผลลัพธ์ขึ้นก่อน: **เสร็จอะไร / ค้างอะไร (รออะไร) / โอต้องทำอะไร** — ไม่โชว์โค้ด/คำสั่ง/path เว้นแต่โอขอ
