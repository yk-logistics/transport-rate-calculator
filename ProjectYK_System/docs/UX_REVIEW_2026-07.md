> หลักที่ใช้มอง: โอกับธุรการทำงานเป็น "กอง" (กองบิล กองสลิป กองงาน) — ทุกหน้าควร
> ① เข้าถึงใน ≤2 คลิกจากเมนู ② ทำซ้ำได้รัวๆ โดยไม่เด้งออกจากหน้า ③ พิมพ์น้อยที่สุด (เดา/จำค่าให้)
> ทำแล้วติ๊ก ✅ / ยังไม่ทำ = ⬜ (เรียงตามความคุ้มต่อคลิก)

## ทำแล้วคืนนี้ (12 ก.ค.)

- ✅ กล่องบิล: กด ➕เข้ารถ แล้วอยู่หน้าเดิม + แบนเนอร์ลิงก์ใบที่สร้าง (เดิมเด้งออกทุกใบ)
- ✅ กล่องบิล: ทะเบียนรายบรรทัด — บิลใบเดียวหลายคัน แยกใบซ่อมให้เอง + พิมพ์เลขท้ายก็จับคู่รถให้ (กฎ 8003=71-8003)
- ✅ กล่องบิล: ปุ่ม "ทิ้งทั้งหมดที่อ่านไม่ผ่าน" (เดิมต้องกดทีละใบ)
- ✅ คีย์บิลยาง: แต่ละเส้นเลือกคันปลายทาง/เก็บสต๊อกได้ในฟอร์มเดียว
- ✅ เมนูหน้างาน: เพิ่มทางลัด 📥 กล่องบิลรอคัด + 🛞 คีย์บิลยาง (เดิมต้องผ่าน /maint ทุกครั้ง)

## ⬜ ข้อเสนอรอบถัดไป (เรียงตามคุ้ม/ชิ้น — ทุกข้อเล็กพอจบใน 1 เซสชัน Opus)

1. **Badge ตัวเลขค้างบนเมนู** — "หน้างาน" โชว์จุดแดงเมื่อมี กล่องบิล ready>0 / กล่องไลน์รอคัด>0
   (โอไม่ต้องเปิดเข้าไปเช็คว่ามีของรอไหม) — ระวัง: query ต่อ page render ให้ cache 60 วิ
2. ✅ ทำแล้ว 12ก.ค. บ่าย — หน้าแรกการ์ด "📥 กล่องบิลรอคัด" (ready + อ่านไม่ผ่าน, gate สิทธิ์)
3. ✅ ทำแล้ว 12ก.ค. บ่าย — หน้ารายการซ่อมโชว์รูปบิลต้นฉบับจากกล่อง (ผ่าน BillInbox.done_action)
4. 🟡 ทำแล้วครึ่งเดียว — /maint/records ฟอร์มรับเลขท้ายแล้ว (_resolve_plate); **เหลือ /fuel + ค้นหากลาง**
5. **ตาราง grid ใหญ่ (daily/billing): ปุ่ม "ค้างหัวตาราง" (sticky header)** — เลื่อนลงแล้วยังเห็นชื่อคอลัมน์
6. **มือถือ: เมนู 5 หมวดบนจอแคบพับเป็น hamburger** — ตอนนี้ flex-wrap ปุ่มล้นสองแถวบนมือถือโอ
7. **ทุกหน้า "กอง" (บิล/ไลน์/สลิป) ใส่ตัวนับความคืบหน้า** — "คัดแล้ว 34/56 วันนี้" เห็นแรงคืบ
8. **หน้า /maint dashboard: การ์ดปุ่มใหญ่เรียงตามที่ใช้บ่อย** — กล่องบิล/คีย์บิลยาง/บันทึกซ่อม ขึ้นก่อน setup ที่นานๆ ใช้ที

## กติกาที่ต้องคงไว้ (อย่าทำพัง)

- ปุ่ม "เข้ารถ/ยืนยัน" = คนกดเท่านั้น (AI เขียนได้แค่ร่าง) — อย่าเพิ่ม "ยืนยันทั้งหมดอัตโนมัติ"

- แก้ template = TemplateResponse(request, name, ctx) (starlette 1.x)
