# Payroll mixed-mode split display — emp #86 (lcb_mixed)

วันที่: 2026-06-25
สถานะ: design approved by โอ

## ปัญหา

หน้า `/payroll/{run}/employee/{emp}` แสดง DailyJob เป็นตารางเดียวรวมกันหมด
สำหรับคนขับ `lcb_mixed` (เช่น emp #86 = นายพชร) แต่ละวันเป็นได้ทั้ง **วันเหมา**
(จ่าย 60% ของ revenue) หรือ **วันเที่ยว** (ค่าเที่ยว + พิเศษ 100/เที่ยว) ปนกัน
คนขับ/โอดูแล้วแยกไม่ออกว่าวันไหนคิดแบบไหน ได้กี่วัน ยอดมาจากอะไร

## เป้าหมาย

แยกการแสดงผลเป็น 3 ฝั่งให้ดูเข้าใจง่าย + เพิ่มรายละเอียดเส้นทางส่งของ
**(ต้นทาง → โหลด/บรรจุ → ปลายทาง)** ทั้งในหน้า detail และสลิปที่คนขับดู

**ไม่แตะ logic การคำนวณเงินเลย** — แค่จัดกลุ่ม + แสดงตัวเลขที่คำนวณไว้แล้ว

## ขอบเขต

- กระทบเฉพาะ `pay_mode == 'lcb_mixed'` — คนขับโหมดอื่นหน้าเดิมไม่เปลี่ยน
- ไฟล์: `main.py` (detail handler), `services/payroll_slip.py`,
  `templates/payroll_employee_detail.html`, `templates/payroll_slip.html`

## การจัดกลุ่มวัน (reuse logic เดิม)

ใช้กติกาเดียวกับ `services/payroll._classify_lcb_days()` ที่ engine ใช้คำนวณจริง
(ratio = trip_fee_driver / revenue_customer):

| กลุ่ม | เงื่อนไข | แสดงเป็น |
|------|---------|---------|
| เหมา | rev>0 และ \|ratio−0.60\|≤0.05 | ฝั่งเหมา (×60%) |
| เที่ยว | rev>0 และ ratio<0.15 | ฝั่งเที่ยว (ค่าเที่ยว + พิเศษ100) |
| ambiguous | rev>0 ratio อยู่กลาง | รวมไว้ใน "ฝั่งเที่ยว" + ป้ายเตือน "ต้องตรวจ" |
| รอลงราคา | rev=0 **แต่มี** origin/dest/customer | กลุ่มรถจอด → ป้าย "รอลงราคา" |
| รถจอด | rev=0 และไม่มี route | กลุ่มรถจอด → ป้าย "รถจอด" |

> หมายเหตุ: "รอลงราคา" คือวันที่วิ่งจริงแต่พี่ตาลยังไม่ลงราคา (rev=0)
> ต้องแยกป้ายไม่ให้ปนกับวันหยุดจริง (ตาม idle-days rule)

ผลตรวจ DB ปัจจุบัน (run 2, emp 86): เที่ยว 13 · เหมา 9 · รถจอด/no-work 12
(แถวสุดท้าย 2026-06-15 มี route แต่ rev=0 → "รอลงราคา")

## helper: render เส้นทาง

ฟังก์ชันเล็กใน slip service สร้างข้อความเส้นทางจาก field ที่มีอยู่:
- ต้นทาง = `origin`
- โหลด/บรรจุ = `pickup_location`
- ปลายทาง = `destination`
- ใต้เส้นทาง: `container_no` · `container_size` ถ้ามี

รูปแบบ: `origin → [โหลด] pickup_location → destination` — leg ที่ว่างยุบหายไป
ไม่ทำให้ลูกศรค้าง

## หน้า detail (payroll_employee_detail.html)

ถ้า `employee.pay_mode == 'lcb_mixed'`: แทนตาราง DailyJob เดียว ด้วย 3 ตารางซ้อนกัน
แต่ละตารางมี header นับวัน + subtotal:

1. **ฝั่งเหมา (N วัน · 60%)** — วันที่ · ลูกค้า · เส้นทาง · รายได้ · ×60%
2. **ฝั่งเที่ยว (N วัน)** — วันที่ · ลูกค้า · เส้นทาง · ค่าเที่ยว · พิเศษ100
3. **วันรถจอด/รอลงราคา (N วัน)** — วันที่ · สถานะ(ป้าย) · เส้นทางถ้ามี

คนขับโหมดอื่น: ตารางเดิม (`{% else %}`) ไม่เปลี่ยน

ส่วน "สรุปการคำนวณ" / petty / fuel ด้านบน-ล่าง คงเดิม

## สลิป (payroll_slip.html + build_payroll_slip_context)

เพิ่ม 3-way split เดียวกันลงใน context (เฉพาะ lcb_mixed) สลิปแสดง:
- บล็อกเหมา: นับวัน + ยอดรวม ×60%
- บล็อกเที่ยว: นับวัน + ค่าเที่ยวรวม + พิเศษ
- บรรทัดรถจอด: นับวัน
แต่ละบรรทัดโยงเข้าสุทธิ; เส้นทางแสดง ต้นทาง→โหลด→ปลายทาง
สลิปคนขับโหมดอื่น: เดิม

## การตรวจย้อนกลับ

- ผลรวมวันทั้ง 3 กลุ่ม = จำนวน DailyJob rows ในรอบ (34)
- ยอด ×60% รวมของฝั่งเหมา ≈ `item.fuel_share_income` baseline (display only, ไม่บังคับเป๊ะ)
- เปิดหน้าจริงเทียบกับ dump DB ก่อนปิดงาน (verification-before-completion)
