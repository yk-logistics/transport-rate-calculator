# โต๊ะเช็คดีล (/quote/deal) — สเปคดีไซน์ (โอเคาะ 6 ก.ค. 2026)

## ปัญหา
ลูกค้าโยนรูท/ราคามา (Excel / PDF / ไลน์ / ปากเปล่า) โอต้องนั่งคิดต้นทุนทีละรูทด้วยเครื่องคิดเดิม (ทีละงาน) เสียเวลามาก ต้องการเครื่องมือ "หลายรูทในตารางเดียว" แบบหน้า Wonder Sub 2026 แต่ใช้กับลูกค้าเจ้าไหนก็ได้ ใน 2 โหมด:
- **โหมดเช็ค**: ลูกค้าให้ราคามา → เห็นกำไร/margin ต่อรูททันที
- **โหมดตั้งราคา**: ลูกค้าให้แต่รูท → ระบบเสนอราคาตาม % เป้า + กางตารางผันน้ำมันยื่นลูกค้า

## คำตอบที่โอเคาะแล้ว
- ของโยนมา: ทุกรูปแบบ (Excel/PDF/ไลน์/ปากเปล่า) → ต้องมี **วางข้อความทั้งก้อน (paste-parse)** + กรอกทีละรูท
- ปลายทาง: บางทีเจาะจงถึงโรงงาน/คลัง → resolve หลายชั้น: คลังสถานที่ → จังหวัด (77) → ลิงก์ Google Maps/พิกัด → กรอก กม. เอง
- โครงเที่ยว: **เลือกได้ต่อดีล** — (ก) วงรอบ ฐาน→จุดรับของ→ปลายทาง→กลับฐาน (แบบ Wonder) (ข) ต้นทาง→ปลายทาง ตรง (ขาเดียว/×2)
- เซฟดีลต่อลูกค้า ดูย้อนหลัง/เปิดแก้ต่อได้

## สถาปัตยกรรม (ทาง A ที่โอเลือก)
หน้าเดี่ยว client-side JS (`ProjectYK_System/app/deal_check.html`) สไตล์เดียวกับ `wonder_sub_cost_2026.html` + endpoint หลังบ้านใน main.py:

| Route | ทำอะไร |
|---|---|
| `GET /quote/deal` | เสิร์ฟหน้า (อ่านไฟล์→HTMLResponse ท่าเดียวกับ /quote) |
| `POST /quote/deal/distance` | รับ 1 รูท: resolve จุด (PlaceCache→จังหวัด→ลิงก์ gmaps/พิกัด) → OSRM → คืน km, ชม.ขับ, วันแนะนำ (ceil ชม./9) + upsert PlaceCache; client วนยิงทีละรูท (เห็น progress + เลี่ยง rate limit OSRM) |
| `POST /quote/deal/save` | upsert DealRecord (snapshot JSON ทั้งดีล) |
| `GET /quote/deal/list` | JSON รายการดีล (ค้นชื่อลูกค้า/ดีลได้) |
| `GET /quote/deal/load/{id}` | คืน snapshot |
| `GET /quote/wonder` | โบนัส: เสิร์ฟเครื่อง Wonder เข้าแอป (ปิดปัญหาปริ้น sandbox ถาวร) |

**สำคัญ:** ทุก route ใหม่ต้องลงทะเบียน **ก่อน** `@app.get("/quote/{qid}")` (main.py ~L9579) ไม่งั้นโดน catch-all ดัก

## ตาราง DB ใหม่ (create_all — SCHEMA_VERSION 46→47)
- `DealRecord`: customer_name, deal_name, status(draft/agreed/rejected/archived), snapshot_json, created_by, created_at, updated_at
- `PlaceCache`: name(index), lat, lon, source(province/link/manual), use_count — จำสถานที่ที่เคย resolve

## เอนจินคำนวณ (ในหน้า — สูตรเดียวกับ TransportRateCalculator/Wonder)
- ต้นทุน: น้ำมัน(km÷กม./ล.×ราคา) + เงินเดือนตามวัน + ประกัน 2 ตัวตามวันทำงานฐาน + สึกหรอ(มูลค่า÷ปี÷365×วัน) + ซ่อม(บาท/กม.) → ×(1+BO%) แล้วบวกค่าเที่ยว×(1+BO%)
- ค่าเที่ยวอัตโนมัติ (กติกาแก้ได้ต่อดีล): ฐาน 500 @≤250กม., +100/ทุก 150กม. (ปัดขึ้น), 10ล้อ +100, โบนัสวันที่ ≥3 +100/วัน
- default: น้ำมัน 37.50, ซ่อม 0, เงินเดือน 0, รถ 700k/8ปี, ประกัน 42,000+13,500, ฐานประกัน 24 วัน/เดือน, BO 15%, เป้า 15/30%
- วันแนะนำ: ceil(ชม.ขับ OSRM ÷ 9) แก้ได้รายรูท
- ราคาเป้า: cost/(1−margin) (นิยาม margin ต่อราคาขาย — ตรงกับคอลัมน์ %กำไร)

## ตารางผันน้ำมัน (โหมดตั้งราคา)
จากราคาต่อรูท (ลูกค้าหรือแนะนำ) กางตารางช่วงน้ำมัน: ตั้งช่วงฐาน + กว้างช่วง (default 2 บาท) + % ปรับต่อช่วง (default 2.5% ท่า Wonder, คิดจากฐาน) → ตาราง รูท×ช่วง พร้อมพิมพ์/CSV

## Paste-parser
แยกบรรทัด → ต่อบรรทัด: ตัดด้วย tab/ช่องว่างยาว → เลขตัวท้ายที่ ≥ 300 = ราคา (ถ้ามี), ข้อความที่เหลือ = ชื่อปลายทาง; แถวพรีวิวแก้ได้ก่อนรับเข้า

## จงใจไม่ทำรอบแรก
อ่าน PDF อัตโนมัติ (วางข้อความแทน) · ไลน์บอท · ผูก RateCard/D1 · หัวลาก (มี 6/10 ล้อ + แก้ กม./ล. เองได้)
