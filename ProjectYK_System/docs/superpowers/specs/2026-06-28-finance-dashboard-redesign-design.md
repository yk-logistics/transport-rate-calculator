# หน้า Finance (CFO) — รีดีไซน์ให้อ่านง่าย เห็นภาพรวม

วันที่: 2026-06-28

## ปัญหา / เป้าหมาย

หน้า `/finance` มุมมองไซท์เดียว (single) มีข้อมูลครบแต่ "อัดแน่น" อ่านยาก:
ปุ่ม 4 ปุ่ม + ย่อหน้าอธิบายยาว + KPI 4 ใบ + ตาราง P&L ตัวเลขล้วน + แผงสุขภาพ +
ตาราง trend 6 เดือน + ตารางต้นทุนต่อคัน — ทั้งหมดเป็นตารางตัวเลขหนาแน่น.

โออยากเห็น **ทั้งหมด** (ไม่ตัดทิ้ง) แต่จัดให้เห็นภาพรวมก่อน แล้วค่อยลงรายละเอียด.

## ขอบเขต (จาก brainstorm กับโอ)

แนวที่เลือก: **A — "งบกำไรขาดทุน" เป็นพระเอก** + กล่องพระเอกแบบ **1 (แท่งเทียบ)**.

**กระทบเฉพาะมุมมอง single เท่านั้น** — มุมมอง compare (เพิ่งทำเสร็จ) ไม่แตะ.

## สิ่งที่ไม่ทำ (YAGNI)

- ไม่แตะ `services/finance.py` / ตัวเลขใดๆ — อ่านจาก `pnl`/`prev_pnl`/`health`/`trend` ชุดเดิม
- ไม่แตะ route handler `finance_dashboard` (ctx เดิมพอ)
- ไม่แตะมุมมอง compare
- ไม่เพิ่ม JS chart library — แท่งทำด้วย `<div>` + Tailwind width % ล้วน
- ไม่ทิ้งตาราง P&L / petty breakdown เดิม — ย้ายไปอยู่ใน `<details>` พับเก็บ

## ดีไซน์ (โครงจากบนลงล่าง — เฉพาะ `view != compare`)

1. **หัว + ตัวกรอง** — เหมือนเดิมเป๊ะ (มุมมอง/ไซท์/ช่วง/include_other + ปุ่มลิงก์)
2. **ย่อหน้าอธิบายช่วงเวลา** — เหมือนเดิม
3. **แถบ KPI 4 ตัว** — เหมือนเดิม (รายรับ · กำไรสุทธิ · ภาระหนี้ · break-even)
4. **🆕 กล่องพระเอก "งบเดือนนี้"** — แทน *การจัดวาง* ตาราง P&L เดิม:
   - แท่งรายรับ (เขียวเต็มความกว้าง = 100%) แสดงยอด `revenue_total`
   - แท่งต้นทุนแยกสีตามก้อน: เงินเดือน/น้ำมัน/สดย่อย/ซ่อม/ดอกเบี้ย
     - ความกว้างแต่ละก้อน = (cost_x / revenue_total) × 100% (เทียบกับรายรับ เพื่อให้เห็นว่ากินรายรับไปกี่ %)
     - ถ้า cost_total > revenue_total (ขาดทุน) แท่งต้นทุนล้นเกิน 100% → cap ที่ 100% เชิงภาพ แต่ legend โชว์ % จริง
   - legend ใต้แท่ง: สี + ชื่อก้อน + บาท + % ของรายรับ
   - กล่องกำไรสุทธิตัวใหญ่ (`net_profit`): พื้นเขียวถ้า ≥0 แดงถ้า <0 + `net_margin_pct`
   - `<details>` "ดูเป็นตารางละเอียด" → ตาราง P&L เดิม (ทุกบรรทัด) + petty-by-cat breakdown เดิม + บรรทัด ภงด.53
5. **แผงสุขภาพธุรกิจ** — เนื้อหาเดิมทั้งหมด (avg/trip, contribution margin, fixed cost, สถานะ)
   วางเป็นคอลัมน์ขวาของกล่องพระเอก (grid 2:1) บนจอกว้าง, ซ้อนบนมือถือ
6. **trend 6 เดือน** — ตารางเดิม ย้ายลงล่าง ใส่ใน `<details>` พับได้ (default เปิด)
7. **ต้นทุนต่อคัน** — ตารางเดิม ล่างสุด `<details>` พับได้

## สี (คงโทนเดิมของระบบ — Tailwind)

- รายรับ = emerald · กำไรบวก = emerald · ขาดทุน = rose
- ก้อนต้นทุน: เงินเดือน=indigo, น้ำมัน=amber, สดย่อย=sky, ซ่อม=cyan, ดอกเบี้ย=slate
