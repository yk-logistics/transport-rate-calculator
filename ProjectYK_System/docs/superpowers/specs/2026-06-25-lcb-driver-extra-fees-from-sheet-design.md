# เงินคนขับ LCB: OT + รับตู้แทน + พิเศษ(กรอกมือ) จากชีท — แก้ engine

วันที่: 2026-06-25
สถานะ: design — รออนุมัติจากโอ
ประเภท: **งานเงิน** (กระทบ net pay) → preflight + recompute + ตรวจย้อนกลับ ก่อนขึ้น server

## สรุปที่โอยืนยัน (จากการไล่คอลัมน์ชีทจริง)

เงินคนขับ LCB มาจากคอลัมน์ AL–AO ในชีทเดลี่ (จับด้วยหัวตาราง ไม่ใช่ตำแหน่ง):
1. **ค่าเที่ยวพขร. (AL)** → `DailyJob.trip_fee_driver` — ✅ ถูกแล้ว ไม่แตะ
2. **รับตู้/คืนตู้แทน (AM)** → fee `pickup_return`/`รับตู้แทน` — **ยังไม่บวก → ต้องบวก**
3. **OT (AN)** → fee `OT`/`ot`/`ค่าล่วงเวลา` — **ยังไม่บวก → ต้องบวก**
4. **พิเศษ (AO)** → fee `special`/`พิเศษ`/`ค่าพิเศษ` (เลขกรอกมือ) —
   **ใช้เลขกรอกมือ เลิกใช้สูตร 100/เที่ยว**

> ⚠️ สำคัญ: P–V (ค่ายกตู้/ผ่านลาน/คลีน/ชอร์/เข้าท่า/ชั่งน้ำหนัก) = สำรองจ่าย
> **ไม่ใช่เงินคนขับ** — ห้ามบวก. ค่าล่วงเวลา(V)ในชีท tab เก่าเป็นสำรองจ่าย แต่
> โซน AL–AO เป็นเงินคนขับ (พขร.=พนักงานขับรถ). fee_type `OT`/`ค่าล่วงเวลา`
> ในDBคือเงินคนขับตามที่โอยืนยันรอบนี้

## การเปลี่ยน engine (services/payroll.py)

### เดิม (ต้องเลิก)
- บรรทัด 909 (lcb_trip) + 950 (lcb_mixed): `other_income += trip_count * 100`
  → สูตรเหมา 100 ทุกเที่ยว **ไม่ตรงความจริง** → ลบทิ้ง

### ใหม่
helper `_sum_lcb_driver_extra_fees(session, emp_id, dates, site_code)`:
- รับ **set ของวันที่** (สำคัญสำหรับ lcb_mixed ที่บวกเฉพาะวันเที่ยว)
- sum DailyJobFee ที่ `lower(fee_type)` อยู่ใน:
  - OT: `{ot, ค่าล่วงเวลา}`  (DBมี `OT` ตัวใหญ่ → lower)
  - รับตู้แทน: `{pickup_return, รับตู้แทน}`
  - พิเศษ: `{special, พิเศษ, ค่าพิเศษ}`
- คืน dict `{ot, pickup_return, special, total}`

ใส่ในแต่ละ mode:
- **lcb_trip** (@~907): dates = ทุกวันในรอบ → `other_income += extra.total`
- **lcb_mao** (@922): dates = ทุกวัน → `other_income += extra.total`
  (วันนี้ mao ไม่มีพิเศษ แต่ถ้ามี OT/รับตู้แทนต้องได้)
- **lcb_mixed** (@929): dates = **ทุกวันในรอบ** (OT/รับตู้แทน/พิเศษ เกิดวันไหนก็ได้
  ไม่ผูกกับ trip/mao day) → `other_income += extra.total`
- note ต่อท้าย: `+ OT x + รับตู้แทน x + พิเศษ x`

> ห้ามแตะ mode นอก LCB (ayu/bigc/office)

## ผลกระทบเงิน (วัดจาก DB ปัจจุบัน — emp86 run2)

| รายการ | เดิม | ใหม่ | ต่าง |
|--------|------|------|------|
| พิเศษ | 100×22เที่ยว = 2,200 | กรอกมือ 12 = 1,200 | −1,000 |
| OT | 0 | 0 | 0 |
| รับตู้แทน | 0 | 0 | 0 |

→ พชร net **ลดลง 1,000** รอบนี้. คนอื่นใน LCB ต้องวัดด้วย preflight
(บางคนพิเศษกรอกมือ > 100/เที่ยว, บางคนน้อยกว่า; OT/รับตู้แทนเพิ่มให้คนที่มี)

## preflight (read-only ก่อน recompute)

สคริปต์ใหม่ `tools/preflight_lcb_driver_fees.py`:
1. ทุก PayRunItem ของ mode LCB ในรอบ **ที่ยังไม่ finalized**
2. ต่อคน: before(สูตรเก่า 100/เที่ยว) vs after(OT+รับตู้แทน+พิเศษกรอกมือ) → diff net
3. สรุปยอดรวมต่อรอบ + list คนที่ net เปลี่ยน
4. ยืนยัน: ไม่แตะรอบ finalized, ไม่แตะ mode อื่น, P–V ไม่ถูกนับ
5. โอดู diff → สั่ง go → recompute เฉพาะรอบที่กระทบ
