# เครื่องมือรีเซตรหัสบนเซิร์ฟเวอร์ (ผ่าน AnyDesk) — กู้บัญชี admin/user ที่ลืมรหัส

**วันที่:** 2026-07-02 · **สถานะ:** รอโออนุมัติ (ยังไม่เขียนโค้ด)
**แก้จากร่างแรก (recovery codes):** โอเสนอใช้วิธีเข้า AnyDesk ไปเจนรหัสบนเครื่องเซิร์ฟเวอร์แทน — ง่ายกว่า ไม่เปิดช่องบนเว็บ

## ปัญหา

- admin รีเซตรหัสให้คนอื่นได้บนเว็บอยู่แล้ว แต่ถ้า **admin (yk1) ลืมรหัสเอง** ไม่มีทางกู้ — ต้องพึ่ง AI/คนรู้เทคนิค SSH เข้าไปแก้ DB (เกิดจริง 2 ก.ค. 2026)
- กฎโอ: ต้องเป็นสิ่งที่โอทำเองได้ไม่ต้องมี AI; ถ้าเป็น script ต้องมี runbook

## ดีไซน์ที่เลือก: ไฟล์ดับเบิลคลิกบนหน้าจอเซิร์ฟเวอร์

**ขั้นตอนใช้งานจริง (มุมโอ):** ลืมรหัส → เปิด AnyDesk เข้าเครื่องเซิร์ฟเวอร์ → ดับเบิลคลิก `RESET_PASSWORD.bat` บน Desktop → หน้าจอโชว์รายชื่อ user ทุกคน เลือกหมายเลข → ระบบเจนรหัสชั่วคราวโชว์บนจอ → กลับมาล็อกอินด้วยรหัสนั้น → ระบบบังคับตั้งรหัสใหม่ทันที

### ส่วนประกอบ (2 ไฟล์ใหม่ ไม่แตะแอป)

1. **`tools/reset_password.py`** (อยู่ใน repo, deploy ไปที่ `YK_MVP\app\` บนเซิร์ฟเวอร์)
   - โชว์รายชื่อ `appuser` ทุกคน (หมายเลข, username, role, สถานะ) → พิมพ์เลือกหมายเลข
   - เจนรหัสชั่วคราวสุ่ม 10 ตัว (อ่านง่าย ไม่มีตัวกำกวม 0/O/1/l) ด้วย `secrets`
   - เขียน `password_hash` (bcrypt ผ่าน `auth.hash_password` ของแอปเอง) + `must_change_pw=1` ลง `app.db`
   - ถามต่อ: "รีสตาร์ทแอปเพื่อล้างตัวล็อก 15 นาทีไหม (y/n)" — ถ้าเพิ่งใส่รหัสผิดเกิน 5 ครั้ง `login_guard` (in-memory) ยังล็อกชื่ออยู่ ต้องรีสตาร์ทหรือรอ 15 นาที; y = Stop/Start scheduled task `YK_MVP_APP` (session cookie ไม่หลุด เพราะ session อยู่ในคุกกี้ไม่ได้อยู่ในเครื่อง)
   - ใช้ python ตัวเดียวกับที่รันแอป (global 3.12 มี bcrypt แล้ว) — เขียน 1 แถวขณะแอปรันได้ (SQLite WAL)
2. **`RESET_PASSWORD.bat` บน Desktop เซิร์ฟเวอร์** — เรียกสคริปต์ข้อ 1 ด้วย python ที่ถูกต้อง + `pause` ท้ายจอ

### ทำไมไม่ทำเป็นหน้าเว็บลับ/localhost-only

cloudflared tunnel ต่อเข้า `127.0.0.1:8010` — ทราฟฟิกจากอินเทอร์เน็ตมาถึงแอป**ในรูป localhost** ดังนั้น route ที่ "เชื่อ localhost" จะโดนยิงจากข้างนอกได้ → ห้ามทำ host-based trust ในแอปหลัก เครื่องมือแยกนอกแอปปลอดภัยกว่า

### Runbook

`docs/MVP_ADMIN_RECOVERY_RUNBOOK.md` — ขั้นตอน AnyDesk + ดับเบิลคลิก (พร้อมรูปแบบจอที่จะเห็น) + แผนสำรองสุดท้ายถ้า bat พัง: ขั้นตอน SSH แก้ DB มือ (แบบที่ทำ 2 ก.ค.)

## สิ่งที่ไม่ทำ (YAGNI)

- ไม่ทำ recovery codes บนเว็บ, ไม่ทำ email reset, ไม่ทำ OTP/2FA
- ไม่มี schema change, ไม่มี route ใหม่, ไม่แตะ `main.py`/`models.py` เลย

## การทดสอบ

1. รันสคริปต์กับ DB ทดสอบ → เลือก user → login ด้วยรหัสชั่วคราวผ่าน + โดนบังคับเปลี่ยนรหัส
2. รหัสชั่วคราวเก่าใช้ไม่ได้หลังตั้งรหัสใหม่
3. ทดสอบจริงบนเซิร์ฟเวอร์กับ user ทดสอบ (ไม่ใช่ yk1) ก่อนส่งมอบ
4. ไม่แตะเงิน — auth ล้วน

## ผลกระทบ

ไฟล์ใหม่ 3 ไฟล์ (script + bat + runbook) — แอปหลักไม่เปลี่ยนแม้แต่บรรทัดเดียว
