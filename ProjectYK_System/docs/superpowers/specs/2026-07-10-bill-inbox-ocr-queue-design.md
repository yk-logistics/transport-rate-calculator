## 1. ปัญหา

บิลซ่อม/ใบเสร็จกระดาษกองสะสมเยอะมาก และจะทยอยเข้าเรื่อยๆ — ปุ่ม 📷 อ่านบิล (v49)
ใช้ได้ทีละใบและต้องเปิดบันทึกซ่อม (รู้ทะเบียน) ก่อน โอต้องการ: ถ่ายรูปทั้งกอง →
ระบบอ่านเองเบื้องหลัง → โอมาไล่คัดตอนว่างว่าใบไหนเข้ารถ ใบไหนเข้า Stock
(ของ Stock ใส่ทะเบียนตอนเบิกออก — flow ตัดสต็อกจากบิลซ่อมมีอยู่แล้ว)

## 3. โมเดลข้อมูล (ตารางใหม่ `BillInbox` — create_all, schema v51)

```
id · photo_path (uploads/bill_inbox/<id>.jpg) · uploaded_by · uploaded_at
status: pending → reading → ready | failed → done | dismissed
ocr_json (ร่างจาก bill_ocr.read_bill: vendor/work_date/plate/lines/total/mismatch)
error (ข้อความพังภาษาคน) · done_action ("record:<id>" | "stock" | "dismissed")
```

กติกา: **AI เขียนได้แค่ ocr_json/status ใน BillInbox** — `MaintRecord`/`StockTxn`
เกิดตอนโอกดยืนยันเท่านั้น (กติกาเดียวกับกล่องรอคัดจากไลน์)

## 4. คิวเบื้องหลัง (โจทย์หลักของโอ: "ไม่ให้กระทบระบบ MVP")

- worker = **thread เดียว** ในโปรเซสแอป แบบเดียวกับ `_todo_scan_maybe_auto`
  (lock กันซ้อน + มาร์คสถานะใน DB) — `claude -p` blocking ~40 วิ/ใบ อยู่ใน thread
  จึงไม่แตะ event loop; ประมวลทีละใบ = โควต้า Max ไหลออกช้าๆ ไม่พุ่ง
- ปลุกเมื่อ: อัปโหลดเสร็จ · เปิดหน้ากล่องบิล · ทุกชั่วโมงถ้ามี pending ค้าง
- restart-safe: คิวคือแถว `status=pending` ใน DB — แอป restart แล้วอ่านต่อเอง;
  แถว `reading` ค้างเกิน 10 นาที = ถือว่าตายกลางทาง ตีกลับเป็น pending
- ใบที่อ่านพัง → `failed` + เหตุผลจริง (เช่น "รูปนี้ไม่ใช่บิลที่มีรายการราคา") + ปุ่มลองใหม่
- **สวิตช์ `bill_ocr_mode` เดิมคุมทั้งฟีเจอร์**: off = worker หยุด + หน้าถูกกัน 403;
  admin (default) = โอคนเดียว

## 5. หน้าจอ `/maint/bills` (admin-gated ตาม `_bill_ocr_allowed`)

1. **อัปโหลด**: input multiple → เซฟรูป + สร้างแถว pending ทันที (ไม่รอ AI — จบใน
   ไม่กี่วินาที ปิดหน้าได้เลย) · จำกัดชนิด/ขนาดเดิม (jpg/png/webp ≤12MB, ext whitelist)
2. **รายการรอคัด**: การ์ดต่อใบ = รูปย่อ + ร่าง (ตารางแก้ได้ทุกช่องแบบร่าง v49) + ธง
   ⚠ ยอดไม่ตรงผลบวก + สถานะคิว (รออ่าน N ใบ / กำลังอ่าน / พัง)
3. **ทางออกต่อใบ** (ปุ่มใหญ่ 3 ปุ่ม):
   - **➕ เข้ารถ**: เลือกทะเบียน (prefill จาก plate ที่ OCR อ่านได้) → สร้าง
     `MaintRecord(kind=repair)` + `MaintPart` ผ่านตรรกะเดียวกับ bulk-add v49
     (ค่าแรง/บริการไม่ตัดสต็อก, `_recompute_maint_costs` คิดยอด)
   - **📦 เข้า Stock**: ต่อบรรทัด map เข้า `Part` (ค้น/สร้างใหม่จากชื่อ) → `StockTxn(in)`
     พร้อมราคา; ไม่ผูกทะเบียน — ตอนเบิกใช้ในบิลซ่อมภายหลังระบบตัด `StockTxn(out)`
     พร้อมทะเบียนตาม flow เดิม
   - **🗑 ทิ้ง** (รูปซ้ำ/ไม่ใช่บิล) — เก็บแถว+รูปไว้ตรวจย้อน ไม่ลบไฟล์
4. เสร็จแล้วการ์ดย้ายไปหัวข้อ "เสร็จแล้ว" (พับได้) พร้อมลิงก์ไปบิล/สต็อกที่เกิด
