> ไม่ใช่เงินคนขับ** → ทิ้งสเปกเก่า, รอบนี้ **display เท่านั้น**

## ความหมายเงิน 3 ฝั่ง (โอยืนยัน)

- 🟢 **รายได้คนขับ** (เข้า net): ค่าเที่ยว/เหมา + โบนัสพิเศษ 100/เที่ยว (เดิม ไม่แตะ)
- 🟡 **สำรองจ่าย** (บริษัทออกแทน วางบิลคืนได้ ไม่ใช่ต้นทุน ไม่ใช่เงินคนขับ):
  คอลัมน์ P–V ทั้งหมด + special + pickup_return
- 🔵 **รายได้บริษัท**: ค่าขนส่ง (revenue_customer) + ค่าเสียเวลา

## สิ่งที่จะทำ (display only)

ในตารางเดลี่ #86 (lcb_mixed) เพิ่มการแสดงผล **โดยไม่แตะตัวเลขเงินที่คำนวณ**:

1. helper `reserve_fees_by_day(session, daily_jobs)` →
   `{daily_job_id: {"lift":x,"yard":x,"clean":x,"shore":x,"port_entry":x,
   "weighing":x,"ot":x,"special":x,"pickup_return":x,"total":Σ}}`
   (อ่าน DailyJobFee, จัด fee_type เป็นกลุ่ม case-insensitive)
2. ในตารางเพิ่มคอลัมน์ **"สำรองจ่าย"** (ยอดรวม X ต่อแถว) — คลิก/hover ดูแยกย่อยได้
   (tooltip: ยกตู้ x · ผ่านลาน x · คลีน x · ...) เพื่อไม่ให้ตารางล้นจอ
3. คอลัมน์ **"ค่าขนส่ง"** (revenue_customer) แสดงเป็นรายได้บริษัท แยกชัดจาก "ได้"
   (เงินคนขับ) ที่มีอยู่แล้ว
4. ป้ายสี/หัวข้อระบุชัด: 🟢 คนขับ · 🟡 สำรองจ่าย · 🔵 บริษัท
   เพื่อกันเข้าใจผิดว่าสำรองจ่าย = เงินคนขับ
