> สถานะ: **ร่าง — รอโอเคาะกติกา 5 ข้อท้ายไฟล์ก่อนลงมือ** (Fable เขียน 12 ก.ค. 2026
> ตามที่โอเล่า flow ของไฟล์ `Salary/2026/6.Jun/LCB/สดย่อยวังน้อย.xlsx`)
> คนทำต่อ: เรียกสกิล yk-money-task ก่อน แล้วทำ TDD ตามลิสต์เทสต์ท้ายไฟล์

## โจทย์จากโอ (12 ก.ค.)

- LCB คนขับเบิกเงินเป็น**รายสัปดาห์** (ไม่ใช่รอหักสิ้นรอบเงินเดือนอย่างเดียว)
- เงินสำรองจ่ายที่มี**เงินทอน** — ทีมไม่รับทอนเป็นสด แต่**เอายอดทอนไปหักตอนทำเบิกสัปดาห์**ของคนนั้น
- ระบบวันนี้รู้จักการหักทางเดียว: ผูก `pay_cycle_tag` แล้วไปโผล่สลิปรอบเงินเดือน → ช่องว่าง

## ที่มีอยู่แล้ว (ห้ามสร้างซ้ำ)

- `PettyCashTxn.pending_amount/pending_note/pending_cleared_at` + หน้า "สดย่อย: รอเคลียร์" = ที่พักเงินทอน
- `deduct_from_driver/deduct_amount/pay_cycle_tag/deduction_status` = เส้นหักผ่านเงินเดือน
- ฟอร์มสดย่อยมี Job Suggester + เดารอบอัตโนมัติแล้ว

## แนวออกแบบที่เสนอ (เล็กที่สุดที่ตอบโจทย์)

1. เพิ่มค่าใหม่ใน `deduction_status` หรือ field ใหม่ `settle_via`: `"payroll"` (เดิม) | `"weekly"` (ใหม่)
2. หน้า "รอเคลียร์": ปุ่มเพิ่ม **"หักกับเบิกสัปดาห์"** ข้างปุ่มเคลียร์เดิม → mark รายการทอนเป็น
   `settle_via=weekly, status=รอหักเบิก` (ยังไม่ปิด จนกว่าจะถูกจับคู่)
3. หน้าใหม่เล็กๆ **"ทำเบิกสัปดาห์ LCB"** (`/petty-cash/weekly`): เลือกสัปดาห์+คนขับ →
   ระบบโชว์ ยอดเบิกที่ขอ − Σ ทอนค้างของคนนั้น = **ยอดจ่ายจริง** → กดยืนยัน:
   บันทึกรายการเบิก (PettyCashTxn direction=out, category=advance_weekly) + ปิดรายการทอนที่ถูกหัก
   (ประทับ pending_cleared_at + note "หักกับเบิกสัปดาห์ W29") — เขียน 2 ฝั่งใน transaction เดียว
4. รายงานย้อนกลับ: หน้า weekly โชว์ประวัติต่อคน (เบิก/ทอน/สุทธิ) ต่อสัปดาห์ — ตรงกับคอลัมน์ในไฟล์ Excel เดิม

## ❓ กติกาที่ต้องให้โอเคาะก่อนลงมือ (ห้ามเดา — กฎเงิน)

1. ทอนหลายรายการ ทบรวมหักในเบิกครั้งเดียวใช่ไหม หรือหักทีละรายการ?
2. รอบ "สัปดาห์" นับ จันทร์–อาทิตย์? หรือรอบวันจ่ายเบิกของทีม (วันไหน)?
3. ถ้าสัปดาห์นั้นคนขับไม่เบิก → ทอนทบไปสัปดาห์ถัดไปเรื่อยๆ? มีเพดานไหม? หรือเกิน X สัปดาห์ให้เด้งไปหักเงินเดือนแทน?
4. ถ้าทอนมากกว่ายอดเบิก → จ่าย 0 แล้วทบส่วนเกิน? หรือไม่ให้เกิด?
5. ยอดเบิก/หักพวกนี้ ต้องโชว์บนสลิปเงินเดือนด้วยไหม (แยกบรรทัด "เบิกรายสัปดาห์ หักแล้วระหว่างรอบ") หรือจบนอกสลิป?

## ลิสต์เทสต์ (เขียนก่อนโค้ด)

- mark ทอนเป็น weekly → ไม่โผล่ในหักรอบเงินเดือน (net_guard: payroll เดิมนิ่ง)
- ทำเบิก: ยอดจ่ายจริง = เบิก − Σทอนค้าง + ปิดทอนครบทุกใบที่เลือก (atomic)
- ทอน > เบิก ตามกติกาข้อ 4 ที่โอเคาะ
- ประวัติต่อคนตรงกับผลบวกมือ
- รายการที่ปิดแล้วกดซ้ำไม่ได้
