# บริษัท / ทิศทาง / รายละเอียดงาน (เก็บยาว — ไม่ต้องพิมพ์ซ้ำในแชต)

ไฟล์นี้เก็บ **ความรู้เชิงบริหารและ workflow จริง** ที่โอเล่าแบบยาวๆ เพื่อให้ Agent ในแชตถัดไป **อ่านจากที่เดียว** แทนการอาศัยประวัติแชตทั้งก้อน

## วิธีใช้

- เมื่อมีเรื่องใหม่ให้เพิ่มหัวข้อด้านล่าง (หรือให้ Agent ช่วยสรุปจากคำพูดแล้วโอแก้คำ)
- รายการที่เป็น **นิยามข้อมูล** (ชื่อคอลัมน์, กฎไซท์) ให้สรุปซ้ำใน `TransportRateCalculator/docs/DATA_DICTIONARY.md` ตามที่กฎโปรเจกต์กำหนด
