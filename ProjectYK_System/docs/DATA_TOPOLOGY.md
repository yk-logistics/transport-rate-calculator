## กฎใช้งาน

- **ก่อนใช้ snapshot ตัดสินใจ ต้องพิสูจน์ว่ามันสด**: เช็คตาราง volatile (todoitem/todosuggest/maintrecord) ว่าขยับระหว่าง snapshot — "ตารางเป้าหมายนิ่ง" แยกไม่ออกระหว่าง "ไม่มีกิจกรรม" กับ "backup ค้าง" จนกว่าจะเห็นตารางอื่นขยับ
- **เพดานโดยนิยาม**: ถ้าถูกจำกัดให้อยู่ local และคำถามเป็นเรื่องเหตุการณ์**หลังตี 3 ของวันนี้** = ตอบไม่ได้ ไม่ต้องขุดต่อ — รายงานเพดานนี้ตรงๆ แล้วขอทางเลือก (ข้อมูลจากโอ หรือสิทธิ์อ่าน server)
- **auditlog**: มีตารางแต่ **ยังไม่ active (0 แถว ณ 10 ก.ค. 2026)** — อย่าหวังพึ่งตอบ "ใครแก้อะไรเมื่อไหร่" จนกว่า P2 audit จะเปิดใช้จริง
