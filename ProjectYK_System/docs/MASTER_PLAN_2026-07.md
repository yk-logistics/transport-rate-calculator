## 1. สิ่งที่ตัด/เลื่อน (ตามที่โอบอก + ผมเห็นด้วย)

- **TMS ติดตามสด / API GPS** → ตัด. ใช้เว็บ GPS ของ vendor ดูเองตามเดิม (ฟรี) — ระบบเก็บแค่ "ผลจบงาน"
- **แอพคนขับแบบเด้งแจ้งเตือน/รับงานในแอพ** → เลื่อนยาว. จ่ายงานผ่านไลน์ (มีตัวช่วยสร้างข้อความอยู่แล้ว) + PWA เดิมเก็บหลักฐาน
- คนขับเป่าแอลกอฮอล์/เช็ครถ มีแล้วใน PWA — เพิ่มเฉพาะ **เช็คอิน 3 จุด + รูปตู้ 4 ด้าน + ปิดงาน** (เฟส E ทำท้ายสุด ถ้าโอยังอยากได้)
- ตรวจน้ำมันกันขาย: มีเครื่องมือ reconcile แล้ว — เพิ่มเป็นรายงานอัตโนมัติทีหลัง ไม่ใช่ของเร่ง

## 2. Roadmap — 5 เฟส ≈ 14 วันทำ (1 วัน = 1 เซสชันโฟกัส ~ครึ่งวันจริงของโอ)

> เรียงตามหลัก: **ปิดเงินก่อน (ใช้ทุกเดือน) → ต่อหัว flow (รับงาน) → เอกสาร → ผู้บริหาร → สนาม**
> ทุกงานเขียน spec + เกณฑ์จบ + ระดับโมเดล — โมเดลเด็กทำตามได้เลย

### เฟส A — ปิดของค้างให้ "ใช้จริงทั้งวงเงิน" (2 วัน) → ระบบเงินครบ 100%
| # | งาน | เกณฑ์จบ | โมเดล |
|---|---|---|---|
| A1 | เคาะ+ลง KB 23 แถว CY ตาม `PREFLIGHT_CY_KB_2026-07-02.md` (รอโอตอบ ทาง B + 7 แถวราคา) | net_guard ผ่าน, สลิป/P&L ตรง | ใหญ่ (งานเงิน) |
| A2 | ออก **ใบเสร็จรับเงิน + ใบหัก ณ ที่จ่าย 3%** จากหน้า KB (ปุ่มพิมพ์ PDF ต่อชุดที่ติ๊ก) | โอกดพิมพ์ได้จริง แทนทำมือ | กลาง |
| A3 | หน้า AR: ปุ่ม "บันทึกรับแล้ว" sync กลับ Google Sheet (ไฮไลท์แถวให้ทีม) — ถามก่อนตามกฎ gsheet | ทีมไม่ต้องไฮไลท์เอง 2 ที่ | กลาง |
| A4 | BigC มิ.ย. ปิดรอบ (เกศศักดิ์/ธนวัฒน์ ค้างคำตอบโอ) + ภาษี BigC เคาะ | payrun BigC จบ | ใหญ่ (เงิน) |

### เฟส B — รับงาน: ราคา + ปฏิทินรถ (4 วัน) → หัว flow ครบ
| # | งาน | เกณฑ์จบ | โมเดล |
|---|---|---|---|
| B1 | **โมดูลใบเสนอราคา**: ย้ายเครื่องคิดเรทจาก GitHub Pages เข้า MVP (หน้า /quote) — กรอกพิกัดลูกค้า/ลิงก์แมพ → กม.ไป-กลับจากท่าเรือ, ทางด่วน, ต้นทุน → ราคาขาย | คิดราคาได้เหมือนหน้าเดิมครบ | กลาง (มีโค้ด HTML เดิมเป็นสเปค) |
| B2 | **เซฟใบเสนอราคา**: ตาราง Quotation (ลูกค้า, โรงงาน, พิกัด, กม., ราคาเสนอ, สถานะ ต่อรอง/ตกลง, ประวัติแก้ราคา) + ค้นหา | เซฟ-แก้-ดูย้อนได้ | กลาง |
| B3 | **ผูกราคาเข้าเดลี่/บิล**: ตอนคีย์เดลี่ เจอลูกค้า+เส้นทางที่มีราคาตกลงแล้ว → เติมราคาอัตโนมัติ + ตอนวางบิลเช็คราคาตรงใบเสนอ | ราคาไม่หลุด ไม่ต้องจำ | ใหญ่ (แตะเงิน) |
| B4 | **ปฏิทินรับงาน/กำลังรถ** (/calendar): มุมมองเดือน/สัปดาห์ ต่อวันโชว์ รถทั้งหมด−จองแล้ว−ซ่อม(จาก maint)−คนขับลา = **รับงานได้อีก X คัน**; คลิกวันเห็นรายคัน; จองงานล่วงหน้าจากหน้านี้ → ส่งเข้า dispatch planner | โอเปิดดูแล้ววางแผนของานล่วงหน้าได้ | กลาง+ใหญ่รีวิว |

### เฟส C — วางบิลอัตโนมัติ (3 วัน)

| C2 | **สร้างใบวางบิลจากเดลี่**: เลือกลูกค้า+ช่วง → ออกไฟล์ตามฟอร์มลูกค้า (เริ่มจากฟอร์มกลางแบบไฟล์ CY/NHL ที่มีโครงใน Drive แล้ว ค่อยเพิ่มรายลูกค้า) + ลงเลข INV วิ่งอัตโนมัติ + เขียนเข้า "รายการรับเช็ค" ใน Sheet (ถามโอก่อนตามกฎ) | ออกใบวางบิลจากระบบได้จริง ≥3 ลูกค้าแรก | ใหญ่ออกแบบ+เด็กทำต่อ |

### เฟส D — มุมมองผู้บริหาร (3 วัน)
| # | งาน | เกณฑ์จบ | โมเดล |

| D3 | ต้นทุนต่อคัน/ต่อเที่ยวสมบูรณ์ (ผูกซ่อม+น้ำมัน+ค่าเที่ยว+ค่างวดรถ) + ธงรถที่ขาดทุน | ชี้ได้ว่าคันไหนควรขาย | กลาง |

### เฟส E — สนาม/หลักฐาน (2 วัน, ทำเมื่อ A-D นิ่ง)

**รวม ≈ 14 วันทำ** (A:2, B:4, C:3, D:3, E:2) — ถ้าโอให้เวลาแบบวันนี้ (ผมทำ 3-4 งาน/เซสชัน) จบได้ใน **~3 สัปดาห์ปฏิทิน** โดย**ปล่อยใช้เป็นช่วง**: จบเฟส A = วงเงินใช้จริง 100% ทันที ไม่ต้องรอเฟสอื่น

## 3. คำถามรอโอเคาะ (ตอบทีเดียวแล้วเดินยาวได้)

1. KB CY: ทาง B (แก้ราคา→5,000 + ใส่ KB, เงินคนขับไม่ขยับ) โอเคไหม + 7 แถวราคาชนยึดฝั่งไหน (ดู PREFLIGHT_CY_KB)
2. ใบวางบิล: เริ่มจากลูกค้า 3 รายไหนก่อน (ผมเสนอ CY, NHL, KLN — ปริมาณเยอะ+ฟอร์มมีตัวอย่างใน Drive ครบ)
3. ปฏิทินรถ: "รถว่าง" นับจากทะเบียนที่ active ทั้งหมดใช่ไหม และคนขับลาบันทึกที่ไหนเป็นทางการ (ตอนนี้ leave กระจายอยู่ในเดลี่)
4. BigC ค้าง: เกศศักดิ์ −3,226 / ธนวัฒน์ 6 วัน / ภาษี BigC — เคาะได้เลยไหม
5. เครื่องคิดเรท GitHub Pages: ลิงก์/ที่อยู่โค้ดล่าสุดอันไหนเป็นตัวจริง (ใน repo มี transport_rate_calculator.html — ใช่ตัวเดียวกับที่โอใช้ไหม)

## 4. กติกาทำต่อ (สำหรับโมเดลเด็ก/เซสชันหน้า)
