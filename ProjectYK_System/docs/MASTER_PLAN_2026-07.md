## 1. สิ่งที่ตัด/เลื่อน (ตามที่โอบอก + ผมเห็นด้วย)

- **TMS ติดตามสด / API GPS** → ตัด. ใช้เว็บ GPS ของ vendor ดูเองตามเดิม (ฟรี) — ระบบเก็บแค่ "ผลจบงาน"
- **แอพคนขับแบบเด้งแจ้งเตือน/รับงานในแอพ** → เลื่อนยาว. จ่ายงานผ่านไลน์ (มีตัวช่วยสร้างข้อความอยู่แล้ว) + PWA เดิมเก็บหลักฐาน
- คนขับเป่าแอลกอฮอล์/เช็ครถ มีแล้วใน PWA — เพิ่มเฉพาะ **เช็คอิน 3 จุด + รูปตู้ 4 ด้าน + ปิดงาน** (เฟส E ทำท้ายสุด ถ้าโอยังอยากได้)
- ตรวจน้ำมันกันขาย: มีเครื่องมือ reconcile แล้ว — เพิ่มเป็นรายงานอัตโนมัติทีหลัง ไม่ใช่ของเร่ง
