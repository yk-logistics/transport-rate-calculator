# คู่มือกู้รหัสผ่าน MVP (ลืมรหัส — รวมถึง admin ลืมเอง)

**อัปเดต:** 2026-07-02 · ทดสอบจริงบนเซิร์ฟเวอร์แล้ว (user ทดสอบ + ล็อกอินผ่าน)

## วิธีปกติ: ดับเบิลคลิกบนเครื่องเซิร์ฟเวอร์ (ทำเองได้ ไม่ต้องมี AI)

1. เปิด **AnyDesk** เข้าเครื่องเซิร์ฟเวอร์ YK
2. ดับเบิลคลิก **`RESET_PASSWORD.bat`** บนหน้าจอ Desktop
3. จอดำจะโชว์รายชื่อ user ทุกคน เช่น `[1] yk1 (admin) โอ` → พิมพ์หมายเลขคนที่จะรีเซต แล้ว Enter
   (Enter เปล่า = ยกเลิก ไม่แก้อะไร)
4. จอโชว์ **รหัสชั่วคราว 10 ตัว** → จด/จำไว้
5. คำถามท้าย "รีสตาร์ทแอปเพื่อปลดล็อกเลยไหม?"
   - ถ้าเพิ่งใส่รหัสผิดเกิน 5 ครั้ง (โดนล็อก 15 นาที) → พิมพ์ `y`
   - ปกติ → Enter ผ่านได้เลย
6. เข้า https://app.yklogistics.uk ล็อกอินด้วยรหัสชั่วคราว → ระบบ**บังคับตั้งรหัสใหม่ทันที**

หมายเหตุ:
- คนอื่นที่ไม่ใช่ admin: ให้ admin รีเซตผ่านหน้าเว็บตามปกติได้ ไม่ต้องใช้ไฟล์นี้
- ถ้าขั้น `y` รีสตาร์ทแล้วฟ้อง error: คลิกขวาไฟล์ .bat → **Run as administrator** แล้วทำใหม่ หรือรอ 15 นาทีเฉยๆ ก็หลุดล็อกเอง
- ตำแหน่งไฟล์จริง: `C:\Users\yklog\YK_MVP\app\reset_password.py` (สำเนาต้นทางใน repo: `ProjectYK_System/tools/reset_password.py`)

## แผนสำรองสุดท้าย (ถ้าไฟล์ .bat หาย/พัง) — สำหรับคนรู้เทคนิค/AI

ผ่าน SSH (`yklog@100.97.150.114` ทาง Tailscale):

1. สร้าง hash รหัสใหม่ (เครื่องไหนที่มี bcrypt ก็ได้):
   `python -c "import bcrypt; print(bcrypt.hashpw(b'<รหัสใหม่>', bcrypt.gensalt()).decode())"`
2. เขียนลง DB เซิร์ฟเวอร์ (`C:/Users/yklog/YK_MVP/app/app.db`):
   `UPDATE appuser SET password_hash='<hash>', must_change_pw=1 WHERE username='yk1';`
3. ถ้าโดนล็อก 15 นาที: รีสตาร์ท scheduled task `YK_MVP_APP` (Stop → เช็ค port 8010 ว่าง → Start)
4. ตรวจ: POST /login ด้วยรหัสใหม่ ต้องได้ 303 → `/account/password`

## กับดักที่รู้แล้ว (อ่านก่อนแก้ระบบนี้)

- **DB swap ทับรหัส:** deploy แบบยกฐานข้อมูล (`--with-db`/swap_db) จะทับตาราง `appuser` → รหัสที่เพิ่งเปลี่ยนบนเซิร์ฟเวอร์หาย ต้อง preserve `appuser` จากเซิร์ฟเวอร์ก่อน swap ทุกครั้ง (เกิดจริง 2 ก.ค. 2026)
- **ตัวล็อก 15 นาที** (`login_guard`) อยู่ใน memory ของแอป — รีเซตรหัสไม่ล้างตัวล็อก ต้องรีสตาร์ทแอปหรือรอ
- แอปรันด้วย **venv** `YK_MVP\app\.venv\Scripts\python.exe` (Get-Process จะโชว์เป็น global python เพราะ venv Windows เป็นตัวส่งต่อ — อย่าสับสน)
