# กติกาความปลอดภัยสำหรับทีม YK (1 หน้า — S4)

> พิมพ์แปะออฟฟิศได้ / ส่งเข้ากลุ่มไลน์ทีมได้ — คนคือช่องโหว่ใหญ่สุด ระบบช่วยได้แค่ครึ่งเดียว

## รหัสผ่าน
1. **ห้ามบอกรหัสผ่านใครทั้งนั้น** — แอดมิน/เจ้านาย/ไอที ตัวจริง**ไม่มีวันขอรหัส**
   ใครทักมาขอ (ไลน์/โทร/อีเมล) = มิจฉาชีพ แจ้งโอทันที
2. ห้ามใช้รหัสเดียวกับแอปอื่น (ไลน์/เฟส/ธนาคาร)
3. ลืมรหัส → แจ้งโอ กดรีเซตให้จากปุ่มในระบบ (ได้รหัสชั่วคราว เข้าแล้วระบบบังคับตั้งใหม่)

## เครื่องที่ใช้เข้าระบบ
4. เครื่อง/มือถือที่ล็อกอิน MVP ต้องมีรหัสหน้าจอ + Windows ต้องเปิด Defender
5. ห้ามเข้าระบบจากคอมร้านเน็ต/เครื่องคนอื่น — มือถือตัวเองได้
6. ลุกจากโต๊ะ = ล็อกหน้าจอ (Win+L); ระบบตัด session เองทุก 8 ชม. อยู่แล้ว

## ระวังหลอกลวง (phishing)
7. ลิงก์ระบบจริงมีอันเดียว: **app.yklogistics.uk** — สะกดต่างจากนี้แม้ตัวเดียว = ปลอม
8. ไฟล์แนบ/ลิงก์แปลกในไลน์กลุ่ม อย่ากดก่อนถามคนส่งด้วยช่องทางอื่น
9. เห็นอะไรแปลก (เด้งขอรหัส, หน้าเว็บเพี้ยน, มีรายการที่ไม่ได้ทำ) → บอกโอทันที
   ไม่มีใครโดนดุเพราะรายงาน — โดนดุเพราะเงียบ

## คนเข้า-ออกงาน
10. มีคนออกจากงาน → โอ (หรือแอดมิน) ปิดบัญชีทันทีที่ /admin/users ปุ่ม disable
    **วันเดียวกับวันออก ไม่ใช่สิ้นเดือน**
11. คนใหม่ = บัญชีใหม่ role ต่ำสุดที่พอใช้งาน — ห้ามใช้บัญชีร่วมกัน
    (ระบบจดว่า "ใครทำอะไร" — บัญชีร่วม = จดไม่ได้)

## เรื่องเงิน
12. ระบบเก็บประวัติการแก้ทุกจุดเงิน (/admin/audit) — แก้ผิดไม่ต้องกลัว บอกโอให้ย้อนดูได้
    แต่**แก้เงียบๆ แล้วไม่บอก** ระบบก็เห็นอยู่ดี
13. เลขบัญชีพนักงาน แก้ได้เฉพาะคนที่ได้รับสิทธิ์ — เห็นเลขผิดให้แจ้ง อย่าพยายามแก้เอง
