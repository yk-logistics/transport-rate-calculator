## โครงใบจริง (ทุกลูกค้า pattern เดียวกัน)

- 1 ใบ = 1 งาน/booking (ไม่ใช่รายเดือน) เก็บใน `ใบวางบิล LCB/<ลูกค้า>/<M.YYYY>/`
- ชื่อไฟล์: `<PREFIX><YYMM>-<seq 3 หลัก> <ลูกค้าปลายทาง>.xlsx` (CY มีราคา+OT ต่อท้าย)
- ชีท **"ค่าขนส่ง"** = ความจริง: หัวใบ G8=เลขใบ, K8 หรือ M8=วันที่, C11-13=ชื่อ/ที่อยู่
  ลูกค้า (อยู่ใน template แล้ว ไม่ต้องแตะ); แถวตู้เริ่ม **row 16**:
  A=ลำดับ B=รายการบรรทุก D=เลขตู้ E=ไซส์ F=ทะเบียน G=ลูกค้าปลายทาง
  H=JOB (KMMT=job_ref) หรือ BL (CY=bl_booking) I=วันที่บรรทุก J=ค่าขนส่ง
- ปะหน้า = สูตรอ้างชีทค่าขนส่งทั้งหมด — ไม่ต้องแตะ
- ค่าทดรองจ่าย 2 สไตล์:
  - **KMMT (KTIV):** ชีทแยก "ค่าทดรองจ่าย" mirror แถวด้วยสูตร `=ค่าขนส่ง!X16`
    + J=ยอดต่อตู้; รวม J32; ชีทค่าขนส่งรวม J31 (แถวตู้ 16..30)
  - **CY (CYIV):** ในชีทเดียว K=ค่าล้าง/ซ่อม L=ค่าใช้จ่าย M=`=SUM(J:L)`;
    รวม M33 (แถวตู้ 16..32); วันที่ใบอยู่ M8

## Runbook: เพิ่มลูกค้าใหม่ (งาน ~30 นาที ทำได้ด้วย Sonnet/Haiku)

1. หา folder ลูกค้าใน "ใบวางบิล LCB" → โหลดใบเดือนล่าสุด 2-3 ใบ
   (ดู `_kb_payout_cache` ก่อน อาจมีแล้ว)
2. dump เซลล์ทุกชีท เทียบกับ pattern ข้างบน — ต่างแค่ตำแหน่ง = แก้ config พอ
3. copy ใบจริงล่าสุด → `app/invoice_templates/<KEY>.xlsx`
4. เพิ่ม `SeriesCfg` ใน REGISTRY (prefix จากชื่อไฟล์จริง, status_codes จากเดลี่ —
   ดู mapping: CJ→CJIV, JGL→JGIV, KTL→KLIV, KAO→MTIV, NHL→NHIV, WHALE→WHIV)
5. รัน verify กับใบจริง ≥2 ใบ (ใช้ DB สำเนา server จาก `C:\Users\guole\YK_BACKUPS_MIRROR`)
   — ต้อง PASS ก่อน merge
6. เทสต์: เพิ่มเคสใน test_invoice_builder.py ถ้าโครงต่างจาก 2 สไตล์เดิม
