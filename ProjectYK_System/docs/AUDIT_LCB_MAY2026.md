## TL;DR (อ่านแค่นี้ก็พอ)

- **ปัญหาหลักอยู่ที่ไฟล์เดียว: งานวิ่ง (daily) + payrun** — fuel กับ petty แทบไม่มีปัญหา
- **payrun draft #1 ใช้ไม่ได้ ตัวเลขล้าสมัย** เพราะถูกคำนวณ **ก่อน** import งานวิ่งชุดล่าสุด 3.5 ชม. → **ต้องกด re-compute ใหม่** (ไม่ใช่บั๊ก engine)
- ระบบกับ Excel **เกือบตรงกัน** เมื่อเทียบในกรอบรอบที่ถูกต้อง — ไม่ต้องลบทำใหม่ทั้งหมด
- **ตอบคำถามโอ "ลบหมด หรือ ปรับ":** → **ปรับ + re-compute** ไม่ต้องลบทำใหม่หมด

## รายละเอียดแต่ละประเด็น

### 1. payrun draft #1 — ตัวเลขล้าสมัย (เรื่องใหญ่สุด แต่แก้ง่าย)
หลักฐาน timeline (created_at ใน DB):
- payrunitem คำนวณ: **27 พ.ค. 12:08**
- งานวิ่ง (source `reimport_lcb_daily`) เข้า DB: **27 พ.ค. 15:38** — หลัง payrun 3.5 ชม.

ผลคือ draft เก็บค่าเที่ยวเกือบเป็นศูนย์ (ประจัก trip_fee=486) และกลุ่มเหมาน้ำมัน net ติดลบหลายหมื่น
**วิธีแก้:** เปิดหน้า payrun แล้ว re-compute / ลบ draft แล้วสร้างใหม่ — engine คำนวณถูกอยู่แล้ว

**ตรวจย้อน:** หลัง recompute ประจัก (emp 89) ควรได้ ≈ ค่าเที่ยว 8,775 + พิเศษ 3,000 (Excel = 9,125 + 2,900)

### 2. แถว "รถจอด" หายตอน import → **หักเงินเดือนผิด** 🔴 (อัปเดต: กระทบเงินจริง)
import script `reimport_lcb_daily.py` มีบรรทัด `if "รถจอด" in status_code: skip` → ตั้งใจข้าม
**ผลที่ตามมา (ค้นพบเพิ่ม):** payroll engine `_count_work_days` ถือว่า "วันที่ไม่มีแถว DailyJob เลย = ขาดงานเงียบ (implicit absent)" แล้ว**หักเงินเดือน+ค่าดูแล** (payroll.py บรรทัด 582-583)
→ ประจักโดนนับขาด **6 วัน** (= 6 แถวรถจอดที่หาย) หักเงินเดือนไป ≈ 2,400฿
→ กลุ่ม lcb_trip ทุกคน recompute ต่ำกว่า Excel **~2,200–4,200฿** เพราะเหตุนี้

**วิธีแก้ที่ถูก:** import แถวรถจอดกลับเข้า DB (status_code="รถจอด", rev=0) — engine จะจัดเป็น `company_no_work` (ไม่หัก) ไม่ใช่ absent
ตรวจย้อน: หลัง import แถวรถจอด → recompute → ประจัก gross ควรขยับจาก 21,159 เข้าใกล้ Excel 23,857

### 2b. ผลพิสูจน์จาก preview script (ไม่เขียน DB)
`tools/preview_lcb_payrun_recompute.py` คำนวณสดทั้ง 21 คน:
- net รวม: draft เก่า **−327,232** (เสีย) → recompute **+303,266** (สมเหตุผล) — ทุกคนกลับเป็นบวก
- กลุ่มเหมา พิชิต: recompute income 46,130 vs Excel 46,570 = ต่าง −440 ✅ (เทียบ gross−น้ำมัน)
- กลุ่ม trip: ต่ำกว่า Excel เป็นระบบ = ผลจากบั๊กรถจอดข้อ 2

### 3. คอลัมน์ไฟล์วางบิลเลื่อน — import script เก่าพังถ้ารันกับไฟล์ปัจจุบัน 🔴
`reimport_lcb_daily.py` เขียนไว้อ่าน:
- col Y (idx24) = ค่าขนส่ง → **ไฟล์ปัจจุบันคอลัมน์นี้คือ "ยอดหัก ภงด.53"**
- col AJ (idx35) = ค่าเที่ยว → **ไฟล์ปัจจุบันคือ "หมายเหตุ"**
- sheet `Daily 16.04.69 - 15.05.69` → **ไฟล์ปัจจุบันไม่มี** (เปลี่ยนชื่อเป็น `Daily` เฉยๆ)

**ในไฟล์ปัจจุบัน ค่าขนส่งจริงอยู่ col 21 (idx20)**
data ที่อยู่ในระบบตอนนี้ตัวเลขถูก → มาจากการ import เวอร์ชันที่ตรงกันก่อนหน้า ไม่ใช่จากไฟล์ใหม่นี้

> ⚠️ **ห้ามรัน `reimport_lcb_daily.py` กับไฟล์ปัจจุบันโดยไม่แก้ column mapping ก่อน** — มันจะลบ data เดิม แล้ว import จากคอลัมน์ผิดทั้งหมด

### 4. petty: รายการ "คืนเงิน" เก็บผิดเครื่องหมาย (บั๊กเล็ก)
"พิชิต คืนค่าน้ำมัน" 27 เม.ย.: Excel = **-120.66** (ลดยอดจ่าย) แต่ระบบเก็บ **+120.66**

fuel script skip คนที่ match driver ไม่ได้ (ตามดีไซน์) — ถูกต้องแล้วสำหรับ payroll รอบนี้
