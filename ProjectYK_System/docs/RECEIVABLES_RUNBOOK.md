## กติกาที่ระบบอ่านจากไฟล์ (โอยืนยัน 2 ก.ค. 2569)

- ไฮไลท์สี**ทั้งแถว** = **รับเงินแล้ว** (เขียว = รับรอบปกติ / เหลือง = รับแล้วแต่คนละรอบโอน)
  → ระบบตัดออกจาก "ค้างรับ" อัตโนมัติ; ดูสีจากช่อง **ชื่อบริษัท (คอลัมน์ C)** — สีเฉพาะช่องหัก ณ ที่จ่าย (F) ไม่นับ
- ไม่มีสี = **ค้างรับ**; คอลัมน์ H (DUE รับเช็ค) = วันนัดรับเงิน → เลยวันนี้ = เลยกำหนด (แดง)
- ยอดที่รอรับ = คอลัมน์ G (เงินหน้าเช็ค = ยอดบิล − หัก ณ ที่จ่าย)
- แถว "รวมเป็นเงิน" / แถวที่ยังไม่มียอด (รอออกบิล) ถูกข้าม; INV เดิมโผล่หลายแท็บ = นับครั้งเดียว (เอาแท็บล่าสุด)
- **อ่านเฉพาะแท็บปี 2026 เป็นต้นไป** — แท็บปีเก่าไฮไลท์อาจไม่อัปเดต กลายเป็นค้างรับปลอม (โอสั่ง 2 ก.ค.)

## ถ้าหน้าเตือน "ยังไม่เห็นไฟล์ของไซต์ ..."

ไฟล์ยังไม่ได้แชร์ให้ระบบ → เปิด Google Drive คลิกขวาไฟล์ "รายการรับเช็ค AYU/LCB ..."
→ Share → ใส่อีเมล service account (หน้าเตือนโชว์อีเมลให้ copy เลย) → สิทธิ์ **Viewer** พอ → รีเฟรชหน้า
ห้ามเปลี่ยนชื่อไฟล์ให้หลุดคำว่า "รายการรับเช็ค AYU" / "รายการรับเช็ค LCB" (ระบบหาไฟล์จากชื่อ)

## แก้ปัญหา

- **ตัวเลขไม่อัปเดต**: ระบบ cache ตามเวลาแก้ไฟล์ — ถ้าเพิ่งแก้ Excel ให้รอ Drive บันทึกสักครู่แล้วรีเฟรช;
  ถ้ายังเพี้ยน ลบโฟลเดอร์ `_ar_cache` ในโฟลเดอร์แอปบน server แล้วรีเฟรช
- **แถวที่ควรตัดแต่ยังโชว์ค้าง**: เช็คว่าไฮไลท์สีที่ช่องชื่อบริษัท (C) แล้วหรือยัง — สีแค่บางช่องไม่นับ
- **รายการไม่มีเลข INV** (เช่น ค่าเช่า/รายการพิเศษ): ถ้าพิมพ์ซ้ำหลายแท็บจะนับซ้ำได้ — ใส่เลข INV กำกับจะแม่นสุด
- โค้ด: `app/services/receivables.py` (parser+สรุป) / หน้า: `templates/finance_receivables.html` /
  เทสต์: `tests/test_receivables_page.py` — parser มีเทสต์ workbook จำลองครบ ไม่ต้องต่อ Drive
