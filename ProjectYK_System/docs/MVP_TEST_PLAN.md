# MVP Test Plan — ทดสอบระบบ end-to-end (เริ่ม 2026-06-10)

แผนทดสอบ MVP ทั้งสาย: รับงาน → จัดรถ → คีย์เดลี่ → วางบิล → เงินเดือน → กำไรต้นทุน
มติทั้งหมดเคาะร่วมกับโอผ่าน grill-me 2026-06-10

## กติกาการทำงาน (อ่านทุกเซสชัน)

1. **โอเปิดเซสชันด้วยคำสั่งสั้น:** `MVP S<เลข> ทำต่อ` → agent อ่านไฟล์นี้ + `MVP_TEST_FINDINGS.md` แล้วลุยต่อ ห้ามให้โอเล่าซ้ำ
2. **`จด: ...`** = บันทึกเข้า `MVP_TEST_FINDINGS.md` (ใช้ได้ทุกเซสชัน)
3. **จบงานทุกก้อน agent ปิดท้ายด้วย:** ✅ เสร็จ / 📋 ค้าง / ➡️ คำสั่งเปิดเซสชันถัดไป และอัปเดตสถานะในไฟล์นี้ก่อนจบ
4. **หนึ่งเซสชันหนึ่ง scope** — งานข้าม scope ให้เบรกแล้วแยกเซสชันใหม่
5. **รันคู่ขนาน 2 หน้าต่างได้:** หน้าต่าง 1 = คุม/จด (ห้ามแก้โค้ด, เป็นเจ้าของ findings) · หน้าต่าง 2 = แก้ตามลิสต์ (ห้ามแก้นอกลิสต์, ห้ามแตะ findings) — **โค้ดถูกแก้จากหน้าต่างเดียวเท่านั้น**
6. **บั๊ก/ความขัดใจ:** จดเข้า findings แล้วแก้เป็นชุดในเซสชัน F (4–8 ข้อ/ชุด, ทีละหน้า) — ยกเว้น **blocker** (คีย์ต่อไม่ได้) แก้ทันที
7. **งานเงิน (วางบิล/เงินเดือน/finalize/แก้ข้อมูล):** agent ต้องโชว์ตัวเลขเทียบ + จำนวนแถวที่กระทบ แล้วรอโอพิมพ์ **"go"** เท่านั้น
8. **ก่อนเซสชันที่แตะข้อมูล:** backup `app.db` → `app.db.backup_YYYYMMDD` (agent ทำเอง)
