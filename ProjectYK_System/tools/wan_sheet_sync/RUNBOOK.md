## ขั้นตอน

1. ดาวน์โหลด xlsx → รัน `multiset_diff.py` → สรุปให้โอ: อะไรเพิ่ม / อะไรขัดแย้ง (**ห้ามเดา conflict — ถามโอทุกตัว**)
2. โอเคาะแล้วค่อย `apply_sync.py apply` (มัน backup ชีทเป็น json ก่อนเขียนเสมอ)
3. รัน `multiset_diff.py` ซ้ำ verify: ต้องเหลือ diff เฉพาะจุดที่ตั้งใจคง
4. ถ้าเขียนแถวเกินท้ายตารางเดิม → `fix_format_notes.py` (ไม่งั้นแถวใหม่ไม่มีขอบ/สี + โชว์เลข 0)

## GOTCHA (เจ็บมาแล้วทั้งนั้น)

- **เศษทศนิยม ≠ conflict**: คอลัมน์ ลิตร(M)/ค่าเที่ยว(K) เป็นสูตร (`=iferror(O/N,"")`, `=J*0.6` หรือ 0.55/0.9 แล้วแต่คน) สองไฟล์ปัดโชว์ต่างกัน (61.35 vs 61.3) — ตัวสูตรเดียวกัน อย่าไปแก้
- **เขียนสูตร ไม่ใช่ค่า**: อ่าน xlsx 2 รอบ `data_only=True` (ค่า) + `data_only=False` (สูตร) — ช่องไหนเป็นสูตรให้เขียนสูตร ไม่งั้นสูตรชีทพัง; append แถวใหม่ต้องแปลงเลขแถวในสูตร (=J873*0.9 → =J874*0.9)
- **วันที่**: ชีท locale `en_GB` → เขียน string `"30/6/2026"` ด้วย `value_input_option="USER_ENTERED"` ได้เลย
- **เลข 0 ล้น**: ตารางซ่อนค่า 0 ด้วย number format — แถวที่เขียนเกินเขตตารางเดิมจะโชว์ 0 + ไม่มีขอบ → ก๊อปฟอร์แมต (`copyPaste PASTE_FORMAT`) จากแถวในตาราง + ขยาย `setBasicFilter` ถึงแถวสุดท้าย
- **อย่าทับสีของทีม**: ทีมวางบิลไฮไลต์ฟ้าช่องเลขที่ (คอลัมน์ I) — ก่อนก๊อปฟอร์แมตทับแถวที่ทีมแตะแล้ว ให้เว้นช่องนั้น
- **note ห้ามทับ note**: `updateCells fields="note"` ทับ note เดิม — ข้ามช่องที่มี note สำคัญ (A1, ช่องที่โอเคาะ)
- **ทิศทางความใหม่ ตัดสินทีละก้อน ไม่ใช่ทีละไฟล์**: ของพี่หวานคีย์ → xlsx ใหม่กว่า; เลขวางบิล/บิลน้ำมันที่ระบบย้าย → ชีทจริงใหม่กว่า; ค่าชนกันตรงๆ → ถามโอ (เคสทองสุข 27/6 โอเอาตามพี่หวาน)
- **quota API**: อ่าน ~60 ครั้ง/นาที — note เยอะให้รวมเป็น `batch_update` ก้อนละ ≤500 requests
