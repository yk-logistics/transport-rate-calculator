# MASTER SPEC

เอกสารนี้เป็นศูนย์กลางข้อกำหนดระบบ (single source of truth) สำหรับโปรเจกต์รวมงานขนส่ง:

- Dispatch/จัดรถ
- Daily operations
- Billing/วางบิล
- Petty cash/สดย่อย
- Payroll/เงินเดือน
- Accounting/รายรับรายจ่าย
- Maintenance & Stock (PM/RM)

## 1) เป้าหมายระบบ

ทำงานจากโปรแกรมเดียวจบทั้งสายงาน ตั้งแต่งานเข้าไปจนถึงรายงานเจ้าของ โดยลดการดึงข้อมูลซ้ำจากหลายไฟล์ Excel

## 2) หลักการออกแบบ

- ใช้ไฟล์เดิมของแต่ละไซต์เป็นฐานเริ่มต้น (AYU, BigC, LCB)
- มี data contract กลาง เพื่อแปลงไฟล์ต่างรูปแบบให้เป็นมาตรฐานเดียว
- ไม่เดาชื่อพนักงานเอง: ต้อง map กับ Master เสมอ
- มี validation + audit trail ทุกขั้นตอน
- รองรับ migration ไปคีย์งานในระบบโดยไม่ทำให้งานสะดุด

## 3) โมดูลหลัก

### 3.1 Dispatch (ต้นน้ำ)
- รับงานจากลูกค้า
- กรอกรายละเอียดงานล่วงหน้า
- จัดรถ/คนขับ
- ดูรายได้สะสมคนขับเพื่อกระจายงานให้สมดุล
- สร้างข้อความแจ้งงานแบบ template สำหรับส่งไลน์กลุ่ม

### 3.2 Daily Operations
- บันทึกงานวิ่งจริงรายวัน
- เลขไมล์ต้น-ปลาย
- เบอร์ตู้ ประเภทงาน สถานที่
- ค่าเที่ยว/พิเศษ/รายการหน้างาน

### 3.3 Billing
- ออกวางบิลอัตโนมัติจาก Daily
- รองรับเงื่อนไขแยกลูกค้า (เอกสาร, format, แนบไฟล์)
- ติดตามสถานะวางบิล/ค้างชำระ/วันเงินเข้า

### 3.4 Petty Cash (สดย่อย)
- โอนล่วงหน้า/สำรองจ่าย
- เงินเบิกคนขับ
- เงินทอนขาด/ไม่ทอน
- รายการวางบิลไม่ได้ (ตัดต้นทุน)
- หนี้ผ่อน/อุบัติเหตุ/รายการ pending เพื่อหักเงินเดือน

### 3.5 Payroll
- Trip/Mao ตามกฎ Master
- ดึง Daily + Fuel + สดย่อยในรอบ 16-15
- หักภาษี, ประกันสังคม, เงินประกันตน
- ออกสรุปเงินเดือนแยกไซต์

### 3.6 Accounting
- สรุปรายรับรายจ่าย
- กระแสเงินสดเข้าออกรายวัน/รายสัปดาห์
- สถานะลูกหนี้/เจ้าหนี้
- สรุปเพื่อเจ้าของ + ใช้ยื่นภาษี

### 3.7 Maintenance & Stock
- PM ตามระยะ/เวลา
- RM งานซ่อมฉุกเฉิน
- ประวัติยางรายเส้น
- สต็อกอะไหล่ + จุดสั่งซื้อขั้นต่ำ
- คุมร้านซ่อม/ร้านอะไหล่/ราคา + เลขไมล์
- KPI ต้นทุนซ่อม/กม. และเรทน้ำมัน

## 4) ข้อมูลกลาง (Core Entities)

- EmployeeMaster
- VehicleMaster
- JobOrder (จาก Dispatch)
- DailyJob
- FuelTxn
- AdvanceTxn
- BillingDoc
- PayrollResult
- MaintenanceJob
- StockMove

## 5) Job Lifecycle (ภาพรวม)

1. Draft job (รับงานลูกค้า)
2. Planned (จัดรถ/คนขับแล้ว)
3. In progress (กำลังวิ่งงาน)
4. Completed (งานจบ + ยืนยันข้อมูล)
5. Billable / Non-billable
6. Invoiced
7. Paid / Partial / Overdue
8. Closed (ปิดรอบบัญชี)

## 6) รอบบัญชีและเงินเดือน

- รอบมาตรฐาน: 16 เดือนก่อน -> 15 เดือนปัจจุบัน
- ทุกโมดูลต้องอิงรอบเดียวกันเพื่อ reconcile ได้

## 7) Validation สำคัญ

- ชื่อพนักงานไม่ match Master ต้องให้ผู้ใช้เลือก map
- ค่าเที่ยวว่างต้องบังคับระบุ (หรือยืนยันยกเลิก)
- น้ำมันต้องกรองวันที่ในรอบเท่านั้น
- เบอร์ตู้ซ้ำตรวจตามข้อยกเว้นที่กำหนด
- รายการสดย่อยที่ยัง pending ต้องถูกหักในรอบที่กำหนด
