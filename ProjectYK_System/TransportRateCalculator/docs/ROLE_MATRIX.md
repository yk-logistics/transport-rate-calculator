# ROLE MATRIX

เอกสารกำหนดสิทธิ์และหน้าที่ผู้ใช้งานในระบบเดียว

## 1) Dispatcher / จัดรถ

**รับผิดชอบ**
- รับงานจากลูกค้า
- วางแผนงานล่วงหน้า
- จัดรถ/คนขับ
- แจ้งงานผ่านไลน์กลุ่มจาก template ระบบ

**สิทธิ์**
- สร้าง/แก้ไข JobOrder
- ดูรายได้สะสมคนขับ (เฉพาะเพื่อกระจายงาน)
- ดูสถานะรถว่าง/ไม่ว่าง

## 2) Daily Operator / คีย์เดลี่

**รับผิดชอบ**
- บันทึกข้อมูลวิ่งจริง
- อัปเดตเลขไมล์, เบอร์ตู้, ค่าหน้างาน

**สิทธิ์**
- แก้ DailyJob ก่อนปิดรอบ
- แนบเอกสารหน้างาน/รูปถ่าย

## 3) Billing Operator / วางบิล

**รับผิดชอบ**
- ตรวจความครบถ้วนงานที่วางบิลได้
- ออกใบวางบิลตาม customer profile
- แนบเอกสารประกอบและส่งลูกค้า

**สิทธิ์**
- ออก/ยกเลิก/ออกใหม่เอกสารวางบิล
- ตั้งสถานะ invoice (sent/paid/overdue)

## 4) Petty Cash Controller / คุมสดย่อย

**รับผิดชอบ**
- บันทึกธุรกรรมเงินสดย่อยทุกรายการ
- จัดการรายการ pending หักเงินเดือน
- ติดตามเงินทอนและรายการเบิก

**สิทธิ์**
- เพิ่ม/แก้ไข AdvanceTxn
- ตั้งประเภทรายการ: billable/non-billable/pending

## 5) Payroll Officer / เงินเดือน

**รับผิดชอบ**
- ปิดรอบเงินเดือนรายไซต์
- ตรวจหักสดย่อย/น้ำมัน/ภาษี/ประกันสังคม
- ออกสรุปเงินเดือนและ audit

**สิทธิ์**
- รัน Payroll Engine
- approve รอบเงินเดือน

## 6) Accounting / บัญชี

**รับผิดชอบ**
- สรุปรายรับรายจ่าย
- ติดตามลูกหนี้/เจ้าหนี้
- สรุปภาษีและรายงานให้เจ้าของ

**สิทธิ์**
- ดูข้อมูลทุกโมดูล (read)
- ปิดบัญชีรายเดือน

## 7) Maintenance Supervisor / ซ่อมบำรุง

**รับผิดชอบ**
- วางแผน PM
- เปิดงาน RM
- บริหารสต็อกอะไหล่/ยาง
- คุมต้นทุนซ่อมรายคัน

**สิทธิ์**
- เปิด/ปิดงานซ่อม
- ตัด/รับสต็อก
- จัดการ vendor ร้านซ่อม

## 8) Owner / ผู้บริหาร

**รับผิดชอบ**
- ติดตาม KPI ธุรกิจ
- ตัดสินใจเชิงกลยุทธ์

**สิทธิ์**
- dashboard ทุกมุม
- ไม่แก้เอกสารปฏิบัติการโดยตรง (ยกเว้น override เฉพาะกรณี)

## 9) Admin IT

**รับผิดชอบ**
- จัดการผู้ใช้และสิทธิ์
- สำรองข้อมูลและกู้คืน
- ดูแลเสถียรภาพระบบ

**สิทธิ์**
- full system admin

## 10) หลักการควบคุมสิทธิ์

- ใช้ role-based access control (RBAC)
- แยกสิทธิ์ "แก้ไข" ออกจาก "อนุมัติ"
- หลังปิดรอบ เอกสารต้อง lock
- ทุกการแก้ไขสำคัญต้องเก็บ audit log (ใคร, เมื่อไร, แก้อะไร)
