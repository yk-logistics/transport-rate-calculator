# BIGC BRANCH RATE SPEC

การคิดค่าขนส่ง + ค่าเที่ยวคนขับ สำหรับลูกค้า Big C อิงประเภทงานในคอลัมน์ `รับตู้`

---

## 1) ประเภทงาน BIGC

| code | ชื่อ | คำอธิบาย |
|---|---|---|
| `รับรถ` | เริ่มขึ้นขับรถ | event — ไม่ใช่เที่ยววิ่ง ไม่เก็บเงิน ไม่จ่ายคนขับ |
| `1DH` | Direct Backhaul | วิ่งตรงจากคลังไปรับ backhaul |
| `1Big c` | สายสั้น กทม./ปริมณฑล (main) | สาขาหลักของเที่ยว (ที่ไกลสุด) |
| `1+` | สายสั้น พ่วงสาขาเพิ่ม | ทุกสาขาที่เพิ่มจาก `1Big c` |
| `2BigC` | สายยาว ต่างจังหวัด (main) | สาขาหลักของเที่ยว (ที่ไกลสุดใน ตจว.) |
| `2++` | สายยาว ต่างจังหวัด พ่วงสาขาเพิ่ม | ทุกสาขาที่เพิ่มจาก `2BigC` |

---

## 2) สูตรคิดเงิน

### 2.1 สายสั้น (1Big c + 1+)

**ค่าขนส่ง (ลูกค้าจ่ายบริษัท):**
- สาขาหลัก (`1Big c`) = **เรทของสาขาที่ไกลสุด** ในเที่ยวนั้น (อ้างอิงตารางสาขา)
- สาขาพ่วง (`1+`) = **400 บาท / สาขา**

**ค่าเที่ยว (บริษัทจ่ายคนขับ):**
- `1Big c` = **250** บาท (fixed)
- `1+` = **100** บาท / สาขา

### 2.2 สายยาว (2BigC + 2++)

**ค่าขนส่ง (ลูกค้าจ่ายบริษัท):**
- สาขาหลัก (`2BigC`) = **เรทของสาขาที่ไกลสุด** ในเที่ยวนั้น (อ้างอิงตารางสาขา)
- สาขาพ่วง (`2++`) = **600 บาท / สาขา**

**ค่าเที่ยว (บริษัทจ่ายคนขับ):**
- `2BigC` = **ตามระยะทาง** (อ้างอิงตารางสาขา — column `driver_trip_fee`)
- `2++` = **200** บาท / สาขา

### 2.3 `1DH`
- ยังไม่ชัดเจน — ต้องยืนยันกับผู้ใช้

## 3) ตารางสาขา BigC (ต้องได้จากผู้ใช้)

ผู้ใช้มีไฟล์จากลูกค้า โครงสร้างคาดว่า:

```
bigc_branches
  branch_code        (เช่น 0045)
  branch_name        (เช่น "สาขาหัวหิน")
  region             (กทม/ปริมณฑล/ตจว)
  distance_km        (กิโลเมตรจากจุดตั้งต้น)
  customer_rate      (บาท — ใช้เมื่อเป็น main 1Big c / 2BigC)
  driver_trip_fee    (บาท — ใช้เมื่อเป็น main 2BigC)
  valid_from
```

**Action**: ขอไฟล์ต้นฉบับจากผู้ใช้ → สร้างสคริปต์ `tools/import_bigc_branch_rates.py` → ลง DB

## 4) ตัวอย่างการคำนวณ

### กรณี 1: สายสั้น 3 สาขา
- เที่ยว: `1Big c` = สาขา A (90 กม., rate 1800), `1+` = สาขา B, `1+` = สาขา C
- ค่าขนส่งลูกค้า = **1800 + 400 + 400 = 2,600**
- ค่าเที่ยวคนขับ = **250 + 100 + 100 = 450**

### กรณี 2: สายยาว 2 สาขา
- เที่ยว: `2BigC` = สาขา X (450 กม., customer rate 5500, driver fee 1500), `2++` = สาขา Y
- ค่าขนส่งลูกค้า = **5500 + 600 = 6,100**
- ค่าเที่ยวคนขับ = **1500 + 200 = 1,700**

---

## 5) Logic ตรวจสอบใน UI

- เที่ยวหนึ่ง ๆ ต้องมี main 1 สาขา (`1Big c` หรือ `2BigC`)
- จะมี `1+` ได้เฉพาะตามหลัง `1Big c` ในวันเดียวกัน/รถเดียวกัน
- จะมี `2++` ได้เฉพาะตามหลัง `2BigC` ในวันเดียวกัน/รถเดียวกัน
- รวม group เป็น `trip` เดียวกัน → คำนวณค่าขนส่ง+ค่าเที่ยวรวมต่อ trip
