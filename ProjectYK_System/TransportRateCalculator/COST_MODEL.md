# Cost Model (TransportRateCalculator)

เอกสารนี้เป็น baseline ล่าสุดของโมดูล `คำนวณต้นทุน` สำหรับเปิดแชตใหม่แล้วทำงานต่อได้ทันที

## 1) หลักการ

- แยก `ต้นทุน` ออกจาก `กำไร` ชัดเจน
- `ค่าซ่อม/ยาง/อะไหล่` เป็นต้นทุนเสมอ (ไม่ซ่อนในกำไร)
- มี `ต้นทุนการเงิน` จากเครดิตลูกค้า เพื่อสะท้อน cash flow จริง

## 2) ตัวแปรหลัก

- ระยะทางรวมจาก Route Segments
- เพิ่มเส้นทางใหม่ได้โดยกรอกแค่กม. (ชื่อไม่บังคับ)
- ช่องระยะทางรองรับสูตร เช่น `43*2`, `=43*2` และมีติ๊กไป-กลับ (x2)
- เรทน้ำมัน, ราคาน้ำมัน, วันทำงานของงาน
- เงินเดือน/ค่าดูแลรถ, ประกันรถ/สินค้า, สึกหรอ
- Maintenance mode: `บาท/กม.` หรือ `% ค่าน้ำมัน`
- ค่าเที่ยว, ทางด่วน, ชอร์
- ราคาขายลูกค้า
- เป้ากำไร 2 ค่า: `% เป้า 1`, `% เป้า 2` (ปรับได้)
- ต้นทุนเงินต่อปี, เครดิตลูกค้า, สัดส่วนต้นทุนที่ต้องสำรองเงินสดเอง

## 3) สูตรคำนวณหลัก

### 3.1 น้ำมัน
- ลิตร = ระยะทางรวม / เรทน้ำมัน
- ค่าน้ำมัน = ลิตร * ราคาน้ำมัน

### 3.2 ต้นทุนรายวัน/คงที่
- ค่าแรง+ดูแลรถต่อวัน = (เงินเดือน + ค่าดูแลรถ) / 30
- ค่าแรง+ดูแลรถของงาน = ต่อวัน * วันทำงาน
- ประกันรถของงาน = (ประกันรถต่อปี / (ฐานวันทำงานประกัน*12)) * วันทำงาน
- ประกันสินค้าของงาน = (ประกันสินค้าต่อปี / (ฐานวันทำงานประกัน*12)) * วันทำงาน
- สึกหรอของงาน = ((มูลค่ารถ+หาง / อายุปี) / 365) * วันทำงาน

### 3.3 ซ่อมบำรุง
- mode บาท/กม. => ระยะทางรวม * rate
- mode %ค่าน้ำมัน => ค่าน้ำมัน * (rate/100)

### 3.4 รวมต้นทุน
- ต้นทุนก่อน Back office = น้ำมัน + คงที่/รายวัน + ซ่อมบำรุง + รายเที่ยว
- Back office = ต้นทุนก่อน Back office * (%Back office / 100)
- ต้นทุนรวม = ต้นทุนก่อน Back office + Back office

### 3.5 ต้นทุนการเงิน
- ฐานที่ต้องแบก = ต้นทุนรวม * (สัดส่วนสำรอง/100)
- ต้นทุนการเงิน = ฐานที่ต้องแบก * (ดอกต่อปี/100) * (วันเครดิต/365)
- ต้นทุนรวมหลังการเงิน = ต้นทุนรวม + ต้นทุนการเงิน

### 3.6 ราคาแนะนำและกำไร
- ราคาแนะนำเป้า 1 = ต้นทุนรวมหลังการเงิน * (1 + เป้า1/100)
- ราคาแนะนำเป้า 2 = ต้นทุนรวมหลังการเงิน * (1 + เป้า2/100)
- กำไรก่อนการเงิน = ราคาขายลูกค้า - ต้นทุนรวม
- กำไรหลังการเงิน = ราคาขายลูกค้า - ต้นทุนรวมหลังการเงิน
- Margin ก่อน/หลังการเงิน = กำไร / ราคาขายลูกค้า

## 4) การแสดงผลที่ใช้อยู่

- KPI แสดง:
  - ราคาเป้า 1/2
  - % น้ำมัน, % ซ่อมบำรุง, % คนขับ ต่อราคาขาย
  - % กำไรก่อนการเงิน และ % กำไรหลังการเงิน
- ตาราง breakdown แสดง `% ของราคาขายลูกค้า` ทั้งตาราง

## 5) ค่า default ล่าสุด

- เรทน้ำมัน = 3 กม./ลิตร
- ราคาน้ำมัน = sync จากด้านบน (ถ้ามี)
- ฐานวันทำงานสำหรับคิดประกัน = 24 วัน/เดือน
- Maintenance mode = บาท/กม., rate = 1.5
- ค่าทำชอร์ = 100 บาท/เที่ยว (ปิดไว้ default)
- Back office = 15%
- เป้ากำไร 1 = 15%, เป้ากำไร 2 = 30%
- ต้นทุนเงินต่อปี = 12%
- เครดิตลูกค้า = 45 วัน
- สัดส่วนต้นทุนที่ต้องสำรองเงินสด = 100%

## 6) บันทึกและซิงก์

- Local save/load + export/import JSON
- Sync with Google Drive ผ่าน Apps Script
- ตัวเลือกอัตโนมัติ:
  - Auto name on save
  - Auto sync after save
  - Auto load from Drive on open

## 7) หมวดแผนที่

- รองรับทั้งลิงก์ Maps และพิกัดปลายทาง `lat,long`
- มีปุ่มเปิดเส้นทางจากพิกัดโดยตรง (แนะนำเมื่อ short link อ่านยาก)

## 8) เกณฑ์เตือน

- กำไรหลังการเงินต่ำกว่า `% เป้า 1`
- น้ำมัน >50% / >60% ของราคาขาย
- ซ่อมบำรุง >12% ของราคาขาย
- คนขับ >17% ของราคาขาย
- ต้นทุนการเงิน >3% ของราคาขาย
- ระยะทางรวม = 0
