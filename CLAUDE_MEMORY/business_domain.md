## กฎเงินเดือนสรุป

- เงินประกันตน 10,000 หัก 1,000/เดือน
- ประกันสังคม ~5% ฐาน 9,000 (หรือตามสัญญาคนขับ — ดู Employee.pay_cycle_policy)
- เบิก/หัก จากสดย่อย

**BIGC:** ฐาน 9,000 + ค่าเที่ยว + เรทน้ำมันเหลือคืน `(target − actual) × 16`

**1DH (BIGC)** = สาขาเดียว, ใช้เรทตามปลายทาง, ไม่มีค่าเที่ยวแยก (ล็อกแล้ว session #9)

## น้ำมันระบบเหมา LCB (คาลเท็ก) — กฎความรับผิดชอบถัง (โออธิบาย 2026-06-10)

งานตรวจที่กินเวลาโอมากที่สุด: คนขับสับรถบ่อย ต้องไล่ว่ารายการเติมแต่ละครั้งเป็นความรับผิดชอบของใคร

**แบบ 1 — เติมคืนเต็มถัง:** ขึ้นขับครั้งแรกน้ำมันเต็มถัง (ของบริษัท) → ระหว่างขับเติมเองรับผิดชอบเอง → คืนรถ/ตัดรอบต้องเติมคืนเต็มถัง ถ้าไม่เติมคืน คนขับคนถัดไปจะเติมเต็มถังเพื่อ "ตัด" ภาระของคนก่อน (รายการเติมนั้นต้องเก็บกับคนก่อน ไม่ใช่คนเติม)

**แบบ 2 — วัดถังตอนรับ-ส่งรถ:** วัดน้ำมันตอนขึ้นขับ ถ้าไม่เต็มส่วนขาดหักคนขับ(ตามเงื่อนไข) → ระหว่างขับเติมเองเป็นของคนขับ → ตัดรอบ/ลงรถวัดถังอีกครั้ง น้ำมันที่เหลือบริษัทจ่ายคืนคนขับ; ถ้าคนเดิมขับต่อ ยอดที่บริษัทจ่ายคืนจะถูกยกไปหักในรอบถัดไป

**กับดักหลัก:** รถคันเดียวกัน คนขับ A → B รายการเติมล่าสุดของ A ต้องดูว่า A เติมแล้วขับต่อ หรือเติมแล้ว B ขับเลย — ตัดสินจาก timeline เดลี่ (ใครขับคันไหนวันไหน) ประกบกับวันเติม

**สถานะระบบ (มติ 2026-06-10):** MVP เก็บแค่ยอดหักน้ำมันสุดท้ายที่โอคำนวณแล้ว (จากไฟล์ Y2026-น้ำมันคาลเท็ก / บันทึกประจำเดือน หัวลาก) — **ฟีเจอร์ auto-attribution (ไล่ timeline เดลี่ × fueltxn แล้วชี้รายการกำกวมให้โอตัดสิน) = งานใหญ่ลำดับแรกหลัง MVP ผ่าน**

## กฎความเสี่ยงข้อมูล

- **ชื่อคนขับซ้ำข้ามไซต์** → ต้อง alias + preflight ก่อนปิดรอบ
- **cycle tag วิ่ง vs จ่าย** → สับสนแล้วเงินผิดเงียบ
- **unlinked records** → ต้อง guardrail ใน UI
- **cross-source check** → daily / fuel / petty / payroll ต้อง cross-check ก่อน finalize

## กำไรต้นทุน (Finance MVP — มติ 2026-06-10)

- **MVP = กำไรขั้นต้นรายไซต์รายรอบ:** รายได้ − ค่าเที่ยว/เงินเดือน − น้ำมัน − สดย่อย (ใช้ข้อมูลที่มีในระบบ)
- **ต้นทุนคงที่** (ค่างวดรถ, ประกัน, เงินเดือนออฟฟิศ ฯลฯ) **ไม่ต้องรอ** — ออกแบบเป็นชั้นหักเพิ่มทีหลังได้เมื่อโอมีข้อมูล ระบบต้องรองรับการเติมย้อนหลังโดยไม่กระทบตัวเลขขั้นต้น

## ราคาเสนองาน Direct-to-store

- เป้า margin: โซนหลัก ~10%, โซนใกล้ (สมุทรปราการ/ฉะเชิงเทรา/ชลบุรี) ~5%
- ปรับราคาน้ำมัน: **1.5% ต่อ 1 บาท** (โอยืนยัน 2026-04-28)
- Consumption: 6W = 5.0 กม./ล., 10W = 4.5 กม./ล.
- ค่าเที่ยวขั้นบันได: 0–200 กม. base, +100 ทุก 100 กม.
