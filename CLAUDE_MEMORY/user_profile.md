## บทบาทและพื้นฐาน

- ชื่อ: **โอ (พงษกาญจน์)**
- บทบาท: ผู้จัดการ / เจ้าของธุรกิจ บริษัท วาย.เค. โลจิสติกส์ โซลูชั่นส์ แอนด์ เซอร์วิส จำกัด
- **Non-coder** — ไม่เขียนโค้ดเอง; ตัดสินใจโดเมน, ทดสอบหน้างาน, แจ้งบั๊ก
- งานหลัก: logistics / ขนส่ง 3 ไซต์ (AYU, BIGC, LCB)

## ภาษาและการสื่อสาร

- คุยเป็น**ภาษาไทย** เสมอ (ธุรกิจ, แจ้งบั๊ก, คำถามทั่วไป)
- ส่งข้อมูลดิบเป็น JSON/CSV ด้วย key อังกฤษ — ไม่พิมพ์ไทยยาวซ้ำ
- ชอบคำตอบ**กระชับ** ไม่อธิบายโค้ด ไม่มีหัวข้อเยอะ

## สิ่งที่โอทำเอง

- ตัดสินใจเรื่องเงิน/ราคา/นโยบาย
- ทดสอบ UI จริงบนเครื่อง
- อนุมัติก่อน finalize payroll / import ข้อมูล

## สิ่งที่ Claude ทำแทน

- เขียน/แก้โค้ด
- วิเคราะห์ข้อมูลจาก Excel/CSV
- สร้างรายงาน/เอกสาร
- deploy ไปยัง GitHub Pages
